# AGENTS/ — AI 代理中间产物统一归口

本目录是 AI 代理（含子代理）施工过程中的**中间产物、临时脚本、门禁日志、待拍板材料**的统一存放处。

## 与根目录 `AGENTS.md` 的区别

| | 根目录 `AGENTS.md` | 本目录 `AGENTS/` |
| --- | --- | --- |
| 性质 | 代理接手本仓库的**入口文档**（事实源链、最小验证清单） | 代理干活产生的**中间产物** |
| 版本管理 | 入库，受版本控制 | 除本 README 外**全部 gitignore**，不入库 |

两者同名前缀但用途无关，勿混淆。

## 子目录约定

| 路径 | 用途 | 谁在写 |
| --- | --- | --- |
| `temp/` | 一次性取证脚本、扫描 JSON、批次 ledger、门禁输出、截图等历史中间产物 | 主代理与子代理 |
| `workspace/temp/` | `scripts/accept.ps1` 的门禁报告（`accept-<分支>-<时间戳>.md`）与每道门禁完整日志（`accept-logs/<时间戳>/`） | 门禁脚本自动写 |
| `artifacts/` | 待用户拍板的交付材料，按批次分子目录（如 `artifacts/<批次名>/`） | 主代理 |

## 纪律

1. **交付物不丢桌面**：待拍板材料写进 `artifacts/<批次名>/`，把完整路径告知用户，由用户自行进目录查看。
2. **新中间产物一律写本目录**，不再往仓库根目录散落脚本、日志、截图。
3. **共享台账不直改**：多会话并行施工时各写独立 ledger 文件，由收口会话合并。
4. **可再生即不入库，但结论级证据须留入库摘要**：本目录内容全部可重算或已归档结论进 `docs/comms/STATUS.md`，故本目录自身不需版本管理（除本 README）。**例外口径**（2026-09-29 建立）：凡入库台账（STATUS、待办清单）引用的**拍板/验收证据**，若逐条详单只住本目录（gitignore、随 cleanup 可能被清），须在版本库内 `docs/comms/evidence/` 留一份**读者安全结论摘要**（判定要点 + 日期 + 指向本机详单的原始指针）。
   - 摘要落点与写法约定见 `docs/comms/evidence/README.md`；台账细节只写一份，本目录留详单、evidence/ 留结论摘要，两者互挂指针不互抄全文。
   - 注：本目录下的**可执行脚本**是否收编进版本库仍是待拍板项（U19=G5），本口径不裁决，只针对文本结论摘要。
5. **不在本目录的禁区**：`worktrees/`（8 月旧代码，约 16 GB）、`data/`（运行时数据与生产库）、`node_modules/`、各端 `dist/` 均维持原位，不迁入。

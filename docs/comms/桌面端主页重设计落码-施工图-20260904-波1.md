### 3.4 六态色带（`schedule/band.ts`，判定顺序照 web `queue-band.ts` 原样，不许改序）

### 3.6 卷尾近 7 天摘要签（`schedule/strip.ts`）

```ts
export interface StripDay { date: Date; weekday: string; tone: 'over' | 'busy' | 'full' | 'free'; count: number }
export function buildSchedStrip(orders: SchedOrder[], canAccept: boolean, quotaApplies?: boolean): StripDay[]
```
今天起 7 天；`weekday`＝一/二/三/四/五/六/日；tone 优先级：该日有 `over` 带 → `over`（朱砂）；有任何带 → `busy`（花青）；空日且 `quotaApplies && !canAccept` → `full`（藤黄＝名额已满）；其余空日 → `free`（`--line2` 素条）。

**收口实测修正三条（9/4，与上文初稿不同，以本条为准）**
1. `quotaApplies` 第三参（默认 true，store 传 `cloud`）：本地记账根本没有名额席位概念，空日不能涂藤黄（那颜色在月历图例里是「名额已满」与「临期」）——本地空日一律素条 `free`。初稿 §3.6 与 §五.4 在这点上自相矛盾，已统一。
2. 逾期单**只压「今天」一格**，不涂满整周：它的计划区间多半整段在过去，按原样算在这 7 天里根本看不见，但它确实压在画师当下；整周涂朱砂等于把「这周全逾期」这句假话告知画师。
3. 已完成单不占未来时间（整条不计入）；未设截稿的在画单画满到窗口末（同月历 fallbackEnd 口径）。

### 3.7 名额「能否接单」（`schedule/accept.ts`，复刻 web `QueueBoard.canAccept`，不匹配中文文案）

```ts
export interface AcceptInput {
  status: string | null
  batchLimit: number | null | undefined
  bufferLimit: number | null | undefined
  quotaRemaining: number | null | undefined
  formalCount: number
  bufferCount: number
}
export function computeCanAccept(input: AcceptInput | null): boolean
```
口径：`input===null`（资料未加载）→ `true`（保守不误伤）；status ∈ break/hidden/full → `false`；`quotaRemaining != null && <= 0` → `false`；`batchLimit != null && formalCount >= batchLimit && bufferCount >= (bufferLimit ?? 0)` → `false`；否则 `true`。

### 3.8 排期数据 store（`stores/schedule.ts`，两页共用，防重复取数）

```ts
export const useScheduleStore = defineStore('desktop-schedule', () => ({ ... }))
// 状态：orders: SchedOrder[] / profile: ArtistProfile | null / loading / failed / loaded
// 派生：mode('cloud'|'local') / formalCount / bufferCount / canAccept / slotText / timelineAvailable / stripDays
// 动作：load(force = false): Promise<void>
```
- `load()`：已 `loaded` 且 `!force` → 立即返回（页面来回切不重复拉）；云端并发 `fetchQueue/fetchBufferQueue/fetchProfile`，**profile 失败不牵连**（canAccept 落保守 true），queue 失败 → `failed=true` 且保留旧数据；本地模式只读 `useLocalLedgerStore()`（未 loaded 先 `loadAll()`），**一个云端接口都不调**。
- `canAccept`：本地模式**恒 false**（无名额概念 → 不标可接单绿点，拍板②）。
- `timelineAvailable`：云端 `true`；本地 `false`（无开工日 → 时间条整块缺席，拍板②）。
- `slotText`：云端 `profile.slotDisplay ?? ''`；本地 `''`。
- 降级纪律：纯浏览器环境（bridge/store 不可用）静默降级不抛错，与既有 store 同款。

## 四、路A 施工单 ＝ 独立排期页三视图（只读）

**页面骨架**（照原型 `#view-schedule`）：`<TitleBar @refresh="reload" />`（顶条一张纸，含窗口控制）→ `.stage > .scroll`（`grid-template-rows:auto minmax(0,1fr)`）→ `.sched-head`（`← 回长卷` → `router.push({name:'home'})`、`<h2>排期</h2>`、右侧 `SegTabs variant="tray"`）→ 内容区 `min-height:0; overflow-y:auto`。

1. **取数**：`const sched = useScheduleStore()`；`onMounted(() => void sched.load())`；`reload()` → `sched.load(true)`。**不许自己写 fetch**。
2. **三页签**：`列表 / 月历 / 时间条`，默认**月历**（照原型 `aria-selected`）；页签项由 computed 过滤——`sched.timelineAvailable===false`（本地模式）时**时间条页签整项不渲染**（纪律 4），已选中则回落月历。
3. **月历 pane**：`.cal-head`（`← 2026年9月 →` 月份导航 + `.ct`）+ `<CalGrid :cells="..." />`（full 态）+ `.cal-legend` 六项图例（正式在画/缓冲区/临期≤3天/逾期/已完成/可接单）；`canAccept` 取 `sched.canAccept`（本地恒 false → 绿点自然不显，图例「可接单」项在本地模式不渲染）。月份游标本页自持（`ref(new Date())` 归一到当月 1 号）。

## 六、收口清单（主代理）

### 6.0 收口实测修正记录（9/4 施工后补；与上文初稿冲突时以本节为准）

1. **`.scroll` / `.body` 行尺寸（防重叠的关键，Playwright 实测钉定）**：初稿的 `minmax(0,1fr)` 会把行压到小于内容高，侧景卡溢出压住卷尾（实测：留言卡底边 608 > 窗高 600，「更多」按钮被卷心里的 `.sec-head` 盖住点不到，窄窗整段错位）。正确口径＝`.scroll{grid-template-rows:auto 1fr auto}` + `.body{grid-template-rows:minmax(min-content,1fr)}` + **`.body` 与三个列子元素一律不写 `min-height:0`**（写了就把自己对行高的 min-content 贡献压成 0，行高再也顶不住内容）。
2. **月历防撑破改由 `contain:size` 承担**：`min-height:0` 并不能降低固有高贡献（只影响布局期的自动最小尺寸），实测月历自然高 587px 会反过来把卷心行顶高、白白多出 180px 内滚。给 compact 态格子加 `contain:size`（内容只裁不计）后，cal 态与 todo 态行高完全一致（1200×600 均 503.7px），月历随窗高 flex 舒展（600 高 406px / 900 高 527px）。窄窗（≤1020）解除 `contain` 并给每行 52px 地板，防止塌成不可读的薄片。
3. **`.mv-pane--cal` 单独给 `min-height:0`**：cal pane 必须能缩（格子自己会裁），todo pane 绝不能给（里面是账本行真数据，缩了就溢出压卷尾）。
4. **`--gap` 基准值补进 `App.vue :root`（既有缺陷根治）**：此前 `--gap` 只在各页矮窗媒体查询里定义，窗高 >700px 时 `var(--gap)` 无值 → 题签/卷心/卷尾三段紧贴、订单速览 chips 也贴死。补 `--gap:16px`（原型 :root 同值），矮窗 `.stage{--gap:12px}` 仍覆盖，默认窗 1200×600 视觉零变化。`--row` 刻意不补：TodayPanel 自带 56px 兜底且已随 826/827 终验定型。
5. **排期 store 三条口径修正**：①`orders` 本地分支改 **computed 实时派生**（不做快照——快照会让画师记一笔后概览句已变、月历纹丝不动）；②记 `loadedMode` + `watch(mode)`，**模式一切换旧数据立即作废并重取**（登录/切出走 SPA 跳转、首页不重挂载，靠 onMounted 兜不住，实测切出后月历会继续显云端客户名＝一页两套真相）；③透出 `localUnavailable`，账本读不到时页面说「本机账本读不到」而不是「你还没记一笔」，且 `load(true)` 会真重读账本（否则「重试」是死按钮）。
6. **时间条坐标系与逾期单**：轴刻度/今天线/横条统一到同一坐标系（几何由 `.tl-canvas` 的 `--tl-pad/--tl-name-w/--tl-col-gap` 三个变量算，初稿今天线的 `calc(12px + N% * (100% - 24px) / 100)` 是非法 CSS，百分比不能乘长度，整条 `left` 被静默丢弃）；逾期未完成且整段落在窗口左外的单**不许消失**（定稿原型把它画在最左、朱砂条标逾期），口径＝从窗口左端起按原计划长度画、文字仍是「逾期N天」。
7. **状态文案/色调表抽成 `components/schedule/statusLabel.ts`**：组件与哨兵测试同源 import（初稿测试在文件里重抄了一份表，被测件改词漏态时测试照绿＝哨兵自我循环）。
8. **顺手修的既有缺陷两处**（不属波1 范围，冒烟实测抓到）：①`modules/viewData.ts` 的 time 视图原样返回 store 响应式代理 → `postMessage` 结构化克隆拒收 Proxy → DataCloneError → 模块永远等不到数据、5 秒后转灰牌（官方示例模块「稿情气象台」正好要 time 视图，一直踩这个坑），改为逐字段拷成素对象；②首页概览句 `daysLeft<=0` 一律说「今日截稿」，逾期 2 天的单也被说成今日截稿、还与前半句「1 笔逾期」自相矛盾，改成本地概览句同款口径（逾期 N 天 + 加重）。
9. **抽屉关闭态加 `inert`**：常驻 DOM + 位移隐藏的抽屉，关着时 Tab 焦点会走进屏幕外的条目（且与 `aria-hidden` 冲突）。
10. **矮窗阈值统一 700px**（排期页原写 680px，与首页/原型漂移，窗高 681~700 时两页来回切会跳档）。

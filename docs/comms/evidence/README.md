# docs/comms/evidence/ — 结论级证据摘要入库约定（2026-09-29 建立）

本目录存放**入库台账所引用证据的结论摘要**。建档缘起：`AGENTS/` 中间产物除 README 外全部
gitignore，一次性取证目录随 cleanup 批次清除（先例见 9/29 记忆审计终裁风险提示第 3 条）；
若台账证据链只指向本机详单，换机或清理后指针即踩空，结论不可再审。

## 最小约定

1. **何时写**：凡 `docs/comms/STATUS.md`、`docs/comms/待办-用户侧清单-*.md` 等入库台账引用的
   **拍板/验收证据**，其逐条详单只住在 `AGENTS/`（gitignore）时，须在版本库内补一份结论摘要。
2. **摘要必含三件**：①判定要点（结论级，读者无需外部上下文即可看懂）；②日期；
   ③指向本机详单的原始指针（写 `AGENTS/...` 路径原样，并注明「仅本机可查，清理后可能已不存在」）。
3. **读者安全**：不抄全文、不含密钥/个人信息/敏感 IP；摘要落点即本目录，命名
   `证据-<主题>-<日期>.md`。
4. **细节只写一份**：结论摘要是「摘要层」，不是第二份详单——逐条裁决、辩论书、脚本仍留本机
   详单目录；台账正文与本摘要之间互挂指针、不互抄全文（STATUS 体例「台账细节只写一份」口径）。

## 边界（待拍板，本约定不裁决）

- `AGENTS/workspace/temp` 下的**可执行脚本**（Playwright/seed 等）是否收编进版本库仍是待拍板项
  （见待办清单 U19＝G5/工单 F-40）。本目录只收**文本结论摘要**，不收编任何脚本。

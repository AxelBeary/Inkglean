## 二、前置准备（终验前先把环境弄到位）

1. **起桌面壳**：`cd desktop && npm run tauri dev`（首次会编译 Rust，几分钟；之后快）。
   - 只想看布局不登录：`cd desktop && npm run dev` 起纯浏览器（端口 14200），但**纯浏览器只能看本地模式且记账读不到**，云端态必须走 `tauri dev`。
2. **窗口尺寸坑（重要）**：窗口几何是**记忆式**的（window-state 插件），装过/跑过的机器首次启动可能仍是旧尺寸。要验默认窗高 780，先手动把窗口拉一下、或删掉窗口状态记忆再看；验「最小窗」时手动缩到最小，应停在 1200×600 缩不下去。
3. **登录**：登录页填 QQ + 验证器六位码（云端模式）。
4. **切本地模式**：墨笔菜单（题签右侧钢笔图标）→ 账号区「切出」→ 直接回本地首页；或登录页选「暂不登录 · 本地模式」。
5. **装示例模块**（验插件列要用）：墨笔菜单 → 工具箱 → 模块管理 → 「装示例模块」→ 重新扫描 → 回首页看插件列。
6. **字号与主题**：都在墨笔菜单里（字号滑块 14~20；外观主题 跟随系统→亮→暗 三档循环）。
7. **云端要有数据才看得出效果**：用你平时那个测试画师账号（本地 docker 里已灌过 SHI- 订单/留言/作品，脚本 `workspace/temp/seed-desktop-testdata.ts` 幂等可再灌）。空账号下首页与排期页会走诚实空态，那是另一组用例（§四 G）。

## 三、终验清单（逐条打勾；每条给「怎么做 → 应该看到 → 不合格长什么样」）

### A. 卷心主位可切换（本批核心新交互）

- [ ] **A1 页签切换**：卷心左上两个纸签「今日要办 / 排期月历」，点一下换一面。
  应该：选中那面是花青字 + 纸底 + 花青内描边；另一面灰字。
  不合格：选中态右上角出现**朱砂红点**（用户明确否过：像未读通知会误导画师）；或切换后两面同时显示/都不显示。
- [ ] **A2 记住选择**：切到「排期月历」→ 完全关掉应用 → 重新打开。
  应该：还是月历那一面。
  不合格：又回到「今日要办」。
- [ ] **A3 今日要办那面没被动过**：切回「今日要办」，云端模式看今日要办账本流（逾期置顶、三色点、金额与截稿文案），本地模式看本地记账面板（含「记一笔」表单）。
  应该：与本批之前一模一样（含撕悬浮占位、专注模式收合）。
  不合格：行高变了、撕出占位不见了、本地记账表单点不动。

### B. 滚动条与窗高体系（827 老病灶，必须复验）

- [ ] **B1 默认窗不出外层滚动条**：窗口拉到默认（1200×780），看整页右侧。
  应该：**没有**窗口级滚动条；只有卷面自己那一根细墨条（内容比窗高时才出现）。
  不合格：出现两条滚动条（外层 + 卷面），或页面能整体上下拖动。
- [ ] **B2 字号最大也不出外层滚动条**：墨笔菜单把字号拉到 20px，再看。
  应该：整页等比放大，仍然只有卷面内滚，外层零滚动条。
  不合格：外层冒出滚动条（这是 827 报障的原病灶：zoom 下 100vh 超窗）。
- [ ] **B3 月历态不额外撑高**：在同一个窗口高度下，「今日要办」与「排期月历」两面来回切。
  应该：两面的卷面滚动量**一样**（月历随窗高伸缩，格子不固定高；600 高窗时月历约 406px、900 高窗时约 527px）。
  不合格：一切到月历就多出一段滚动、月历把卷尾顶出画面、或格子被压成一条看不清日期。
- [ ] **B4 纵向拉高窗口**：把窗口从最矮（600）拉到很高（比如 1000）。
  应该：月历格子跟着长高、账本行变高（≥800 高走舒展档）、卷面滚动消失。
  不合格：拉高后内容还挤在上半段、下面大片空白，或月历不跟着长。

### C. 卷尾「排期 · 近 7 天」摘要签

- [ ] **C1 一眼可读**：卷尾「排期 · 近 7 天」下面七根小竖条，每条上面一个周几字。

  不合格：七根全朱砂（把「这周全逾期」的假话讲给画师）；或本地模式下空日涂藤黄（本地没有名额概念，涂藤黄＝说假话）。
- [ ] **C2 点开分流**：点整条摘要签（任意位置）。
  应该：进独立排期页。
  不合格：只有某个小角落能点；键盘 Tab 到它按 Enter/空格没反应（应可键盘操作）。
- [ ] **C3 本地模式照显**：切出登录回本地，看摘要签。
  应该：照显七根条（按你记账的截稿日落色），空日是素灰条。
  不合格：整条消失（本地也该有）；或显示云端的客户单。

### D. 独立排期页三视图（新页面）

- [ ] **D1 入口都能到**：四个入口逐个试——卷心页签右侧「看全景三视图 ›」/ 卷尾摘要签 / 墨笔菜单「排期三视图」/ 更多抽屉里「板块 → 排期三视图」。
  应该：四个都进同一个排期页；页内左上「← 回长卷」能回首页。
  不合格：某个入口点了没反应；回长卷回到登录页或空白页。
- [ ] **D2 三页签默认月历**：进页面看右上纸签脉页签「列表 / 月历 / 时间条」。
  应该：默认停在**月历**；切换顺滑；选中态无朱砂红点。
- [ ] **D3 月历**：翻月（← 2026年9月 →）、看六态色带与图例。
  应该：格子六态颜色对得上图例（正式在画花青实心 / 缓冲区半透虚线 / 临期≤3天藤黄 / 逾期朱砂 / 已完成石绿 / 未设截稿斜纹）；今天格子有花青内框；**空日子后面跟一个石绿小点＝可接单**（名额满时小点消失、图例里「可接单」那项也不显示）；一格最多露 3 条带，多的画「+N」，鼠标悬停看全部。
  不合格：色带与图例对不上；名额已满还标绿点；「+N」不出来导致格子被撑高。
- [ ] **D4 列表**：切「列表」。
  应该：分「正式区」「缓冲区」两块（有货才出现该区），区头写「N 笔在途」，云端还附名额文案（如「开放中 · 剩 1 席」）；每行＝三色点 + 客户·档位 + 状态纸签 + 截稿文案（逾期朱砂/临期藤黄/宽松花青）。
  不合格：**出现拖拽手柄 ⠿ 或能拖动**（波1 是只读，拖排改期属波2，出现即骗人）；状态显示英文原串（如 `wip`）说明状态表漏登记。
- [ ] **D5 时间条**：切「时间条」，试缩放（2周/1月/3月）与「仅进行中」开关。
  应该：每单一行横条，条色同月历口径，条上写「逾期N天/明天截稿/剩N天/候补」等；**逾期未完成的单出现在最左、朱砂条标逾期**（不会因为计划过期就消失）；朱砂「今天线」与轴刻度、横条**三者对齐同一时间位置**；轴刻度是 4~6 个 `月/日` 标签；右侧一句「N 单未排期未计入」（N=0 时整句不出现）。
  不合格：逾期单不见了；今天线钉在画布最左不随缩放动；轴刻度与横条明显错开一段；条上没有任何文字。
- [ ] **D6 空态与失败态**：用空账号（或断网）进排期页。
  应该：断网/拉取失败 → 一行「排期数据拉取失败，显示的可能不是最新」+「重试」纸签（点了真的重拉）；真没数据 → 云端说「排期空空，去网页端接一单再来」、本地说「排期空空，去首页记一笔」。
  不合格：白屏；或「重试」点了没反应（死按钮）。

## 四、已知诚实账（这些**不是 bug，不必报**）

1. **默认窗 1200×780、云端数据满载时，卷面仍会内滚约 31px**。实测四档：600 高 167px / 780 高 31px / 800 高 11px / 820 高 1px。硬底＝非紧凑档下「经营卡 + 留言卡」本身要 523.7px。用户 9/4 拍板取 780（最小窗 600 不动）。要真零内滚还有两条路：窗高再提到 820，或把紧凑档上限从 700 提到 800（后者会动定稿原型的四档口径）——**亲测后再定，一句话就能改**。
2. **780 高于 1366×768 笔记本的可用高（约 728px）**。若目标画师里有那类屏幕，默认窗高需回退（已登记风险）。
3. **间距有 13 处不是 4px 整数倍**（1/2/3/5/6/7/9/10/13/14/18/22/30px）。这是定稿原型的值，也与既有桌面端基线一致（未改的旧文件里有 11 处），属纸墨「手剪纸」语言的刻意偏离，未擅改。**野生字面圆角已清零**（既有基线还有 10 处），这项优于基线。
4. **本地 `draft`（草稿）单也进月历色带与摘要签**：草稿是画师自己记下的承诺（含截稿日），藏起来会丢信息，故保留。若你觉得「草稿不该算在画」，另立拍板。
5. **`OrdersPanel`（订单速览）的 chips 间距从 0 变 16px**：这是修好既有缺陷的正常结果（此前 `--gap` 无基准值，窗高 >700px 时三段紧贴、chips 贴死）。原型该处是 10px，未回改冻结板块。
6. **VL 视觉评审通道不可用**（配置模型 403 未购买、VL 系模型 404 不存在）。本批布局审计改走「确定性测量 + 主代理逐项 C1-C4/S1-S5 清单复核 + Playwright 实测」。若哪天 VL 通道恢复，可补一轮机器评审。

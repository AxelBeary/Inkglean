# 拾绘模块规范 v0.2（模块 = 插件：写前先报备，越权即停用）

> 日期：2026-08-25 · 状态：🟢 已随插件化研判十条拍板 · 版本：v0.2（红队内攻 + 六家业界对照审计后修订，裁决表见 §八） · 性质：规范设计稿（施工时落代码与校验器）
> 上游拍板：`docs/comms/插件化研判-板块契约-20260825-已拍板.md`（十条全采；模块机制口径由用户亲定：模块必须事先声明联网/读写/联动/后台，必须有一份优秀且合理的规范——本文件即兑现）。
> 一句话：**模块的权限不是壳猜出来的，是模块写进 manifest 的；声明即契约，越权即停用。**

---

## 一、总则（五条原则）

1. **声明先行**：模块的一切能力诉求必须写进 `manifest.json`；未声明的能力桥层一律拒发。
2. **最小够用**：每个能力字段默认最保守值；多声明的能力会被画师在模块管理里看见并构成安装/启用顾虑（商店时代的权限提示就用这份清单）。
3. **人话可见**：每个能力声明都有画师可读的文案（`reason` 字段由模块作者填写，说明「为什么要这个」），模块管理界面逐条展示。
4. **越权即病**：运行期请求超出声明 → 桥层拦截 + 记一次违规；违规累积或恶意尝试 → 该模块单独停用（保留「单独失效」口径）。
5. **规范自身有版本**：manifest 带 `spec` 版本号，壳只认支持的版本区间；旧版本尽力归一、认不了的不加载并说明原因（与 prefs 归一化同款纪律：永不抛错、永不拖垮壳）。

## 二、manifest.json 完整形状（标准 JSON：注释只进字段表不进文件，AI 照抄不出错）

```json
{
  "spec": "1.0",
  "api": "panel@1",
  "minHost": "0.2.0",
  "id": "mood-weather",
  "name": "稿情气象台",
  "description": "把今日排期画成天气的一句话模块",
  "version": "0.1.0",
  "author": "qwqwqq",
  "entry": "panel.js",
  "source": "official",
  "ui": {
    "zone": "aside",
    "heightRule": "stretch",
    "hideable": true,
    "tearable": false,
    "focusPolicy": "fold",
    "styles": []
  },
  "data": {
    "views": ["orders", "stats"],
    "write": {
      "own": true,
      "shared": "none",
      "reason": ""
    }
  },
  "settings": [
    { "name": "days", "type": "pick", "title": "看几天内的排期", "options": ["3", "7"], "default": "3" }
  ],
  "network": {
    "scope": "none",
    "hosts": [],
    "reason": ""
  },
  "linkage": {
    "subscribes": [],
    "emits": []
  },
  "runtime": {
    "lifecycle": "on-view",
    "wakeInterval": null,
    "idlePolicy": "afk-aware"
  },
  "diagnostics": false
}
```

### 字段说明表（取值与裁决规则）

| 字段 | 取值 | 说明与裁决 |
|---|---|---|
| `spec` | 字符串 | 规范版本；壳维护支持区间，区间外拒加载（归一与拒绝的边界：能识别结构就归一，认不出结构才拒） |
| `api` / `minHost` | `panel@N` / 语义化版本 | 接口版本 / 宿主最低版本；任一不符→单独失效（minHost 对标 VS Code engines / Obsidian minAppVersion，别家均必填） |
| `id` | 字符串 | 全局唯一键；**目录名必须与 id 一致，不一致按非法拒载**；同 id 重复注册→后到者拒载并提示（审计 M2） |
| `name` / `description` | 字符串（长度上限） | 平实文案；**一切来自 manifest 的字符串按不可信输入处理：转义 + 限长，永不 v-html**（审计 M9） |
| `version` | 语义化版本 | 独立更新通道用 |
| `source` | **壳判定，模块写了也不算** | 官方=更新通道签名链认定；其余一律「外部/未知」（审计 H4） |
| `entry` | 固定 `panel.js` | 首发钉死文件名与形态（纯 JS 模块）；加载器、AI 生成、人肉排错全靠它 |
| `ui.zone` | core\|aside\|tail | 框架管区位 |
| `ui.heightRule` | fixed-rows\|stretch | 等高纪律 |
| `ui.hideable` | bool | 是否允许画师隐藏 |
| `ui.tearable` | bool | **首发壳侧强制压为 false**（可撕仅官方三件），模块自报无效（审计 M4） |
| `ui.focusPolicy` | keep\|fold | 专注画画模式去留 |
| `ui.styles` | 数组 | 可选款式（装裱同族；全局装裱由壳施加） |
| `data.views` | 视图名数组 | 只能订阅声明过的；视图带本地/云端来源标签，云端专属视图本地模式壳层不渲染（审计 H5）；**字段清单作为规范附件另行拍板，敏感字段默认剔除**（审计 M3） |
| `data.write.own` | bool | 私有存储：独立文件 + 配额上限，不入 data.db、不进导出包；卸载残留有管理页清理入口（审计 M7） |
| `data.write.shared` | none\|ro\|rw | 首发只开 none/ro；rw 留门拒发 |
| `settings` | 数组 | 声明式设置项（name/type/title/description/default）；**设置 UI 由壳统一渲染，模块永不自己画 UI**（对照报告必补项） |
| `network.scope` | none\|lan\|internet | 首发声明了也拒发；模块帧 CSP `connect-src 'none'` 物理断网（见 §六） |
| `network.hosts` / `reason` | — | scope≠none 时必填；人话说明 |
| `linkage.subscribes` / `emits` | 字符串数组 | 首发只认声明不实现总线；**防借道条款：订阅含数据负载的事件须自身持有对应视图声明**（审计 M8） |
| `runtime.lifecycle` | on-view\|resident | resident 首发留门：声明了按 on-view 降级运行并提示，不拒载 |
| `runtime.wakeInterval` | 如 "15m"\|null | resident 唤醒周期，首发拟限最短 5 分钟 |
| `runtime.idlePolicy` | afk-aware\|always | 借键鼠空闲检测（实现依赖 F8，档②排期须后于 F8） |
| `diagnostics` | bool | 可选：壳把报错/违规摘要写**本机**日志；未来若有「导出诊断包」功能须重新过纪律 |
| 未声明字段 | — | 一律按最保守默认值处理（最小够用）；解析容忍度：标准 JSON + 允许 BOM，不容尾逗号与注释（审计 M1） |

## 三、字段分组详解

### 3.1 身份与判定权归属（审计 H4 修订）
`spec/api/minHost/id/version` 是壳做「加载、校验、单独失效」的依据；`api` 或 `minHost` 不符 = 单独失效触发点。**`source` 不是模块自报字段：官方身份只能由更新通道签名链认定，其余一律标「外部/未知」；模块自己写的 source 一律忽略**——透明文件改一个词零成本，自报的信任分级等于没有。

### 3.2 呈现
全部沿用第一方板块契约字段——**模块与第一方板块在壳眼里是同一种东西**，区别只在来源与能力边界。装裱纸式由壳全局施加，模块不得自带配色（token 只进不出）。

### 3.3 数据能力
- `views`：壳的只读数据视图清单（订单/账本/时间统计/留言等），模块只能订阅声明过的；**每个视图带本地/云端来源标签，云端专属视图在本地模式/断网时壳层直接不渲染对应模块**（照 810 隐藏纪律，模式感知永远在壳层）；**视图的字段清单另拍板为规范附件，敏感字段（如客户联系方式）默认剔除**；
- `write.own`：模块私有键值存储——**独立文件、有配额上限（具体数字随施工拍）、不入 data.db、不进导出包**；卸载残留有模块管理页清理入口；
- `write.shared`：对共享业务数据的写权限——**首发只开 `none`/`ro`**，`rw` 字段保留但壳一律拒发（留门）；
- 模块永远拿不到 SQLite 本体与凭据保管柜——**这不是口号，靠 §六实现依托硬保证**。

### 3.4 网络能力
- 首发口径不变：**声明了也拒发**（研判拍板项 7）；但声明字段先行落地，商店时代开闸时直接按声明 + 画师授权放行，规范不用重写；
- `scope` 三值对应用户口径：不联网 / 内网（局域网，如本机 Eagle 一类，口径与 824 第三方接入研判一致）/ 外网；
- `hosts` 白名单 + `reason` 人话说明，未来权限提示直接展示。

### 3.5 联动
模块间事件总线首发不实现，但**事件命名规范先行**：订阅写板块事件名、发布自动带模块 id 命名空间，避免商店时代重定契约。

### 3.6 运行时（用户点名项：长期运行/唤醒）
- `on-view`（默认）：只在首页渲染到该模块时运行，隐藏即停——绝大多数模块应是这类；
- `resident`：常驻后台必须声明 `wakeInterval`（最短周期首发拟限 5 分钟，防滥用）；**首发留门口径钉死：声明了 resident 的模块按 on-view 降级运行并在管理页提示，不拒载**；
- `idlePolicy: afk-aware`：借键鼠空闲检测（实现依赖 F8 空闲检测，档②排期须后于 F8）——画师离开工位，常驻模块自动停摆，与「伴侣不抢戏」哲学同构。

### 3.7 文件变更语义（审计 M6）
模块文件可被 AI 随时直改，口径钉死：**运行期不热更，文件变更下次启动生效**；不做目录监听（留门），模块管理页提供手动「重新扫描」。

## 四、壳的强制点（规范怎么长出牙齿）

| 时机 | 壳做什么 |
|---|---|
| 加载 | 校验 `spec` 区间 + 必填字段 + 枚举合法性 + 目录名/id 一致 + 同 id 去重；非法 → 不加载，模块管理里给原因（归一化纪律：永不抛错拖垮壳） |
| 注册 | `api` 或 `minHost` 不符 → 单独失效态（待更新/移除），其余模块与首页不受影响 |
| 模式过滤 | 云端专属视图对应的模块，本地模式/断网时壳层不渲染（810 纪律，渲染前过滤） |
| 字段覆写 | `tearable` 首发对模块一律压为 false；`source` 一律壳判定；模块自报无效 |
| 运行 | 每次桥调用核对声明：未声明→拒；超范围→拒+记违规；违规达阈（阈值/统计窗口/清零规则随施工拍）→单独停用；**手动重新启用即清零违规计数**（防死状态） |
| 保险丝 | 模块帧心跳超时/DOM 超阈/内存超阈 → 杀帧置灰（实现依托 §六），坏模块永不拖垮首页 |
| 展示 | 模块管理页按 manifest 逐条列出能力（联网/读写/联动/后台/设置项 + reason）+ **停用/移除/查看报错三件操作**；一切文案转义后渲染 |
| 卸载 | 模块目录即插件本体（F1 哲学）；私有存储残留有清理入口 |

### 模块状态机（审计 M5 修订：四态分立）
`正常` ⇄ `停用`（越权达阈或画师手动；手动启用清零违规）；`失效`（api/minHost 不符或加载非法，待更新/移除，不自动恢复）；`灰牌`（运行崩溃被保险丝杀帧，可重试一次，再崩转停用）。四态在模块管理页各有标识与恢复路径，不混同。

## 五、首发实现范围（留门清单）

**首发实现**：身份五件校验 · 呈现字段消费 · `data.views` 只读视图 · `write.own` 私有存储 · `runtime.on-view` · 违规记录与单独停用。

**首发留门不实现**：`network` 实际放行 · `write.shared: rw` · `linkage` 事件总线 · `runtime.resident` 常驻调度（字段先认、行为后开；「认」的含义：声明了留门字段的模块不拒载，按降级口径运行并提示）。

## 六、实现依托（审计 H1/H2/H3 定案：声明的牙齿长在哪）

安全承诺不能悬空，档②开工前以下六条是硬契约：
1. **模块帧跨 origin 隔离**：模块渲染在独立 origin 的沙箱帧（跨源 iframe 或独立 Webview，施工时二选一拍板），不与壳同源；
2. **模块帧不见 `__TAURI__`**：Tauri IPC 只对壳窗口发放，沙箱帧拿不到任何原生调用（将来壳接入本地 SQLite 后，模块帧也绝无可能借 IPC 碰 data.db）；
3. **网络物理断**：沙箱帧注入 CSP `connect-src 'none'`（fetch/WebSocket/XHR 全死）——「首发不联网」靠这一层保证，不靠模块自觉；将来开闸时按声明 + 画师授权改 CSP，而非放开模块直接联网；
4. **能力桥 = postMessage + 握手口令**：模块帧与壳的唯一通道，握手由壳发起，模块无法伪造桥消息；
5. **资源保险丝**：沙箱帧心跳失联/渲染超阈 → 壳杀帧置灰（配合 §四保险丝行）；同步死循环靠独立帧的进程边界兜底，不阻塞首页；
6. **存储隔离**：模块无 localStorage/cookie 可用，私有存储一律走桥申请（对应 `write.own`）。

- **对照报告采纳**：补 `entry`（钉死 panel.js）· `minHost`（宿主最低版本）· `description` · `settings`（声明式设置项，壳统一渲染，抄 Raycast 最小集）· `diagnostics`（可选）；明确不补：图标（装裱由壳统辖）、license（首发自用不构成分发，商店时代再议，AGPL 衍生作品问题无判例级定论）、模块间依赖、i18n、分类/平台/赞助链接（单画师单平台，照抄是债）、签名指纹（签的是包不进 manifest）。

**链路设计（新建 `e2e/tests/e11-compliance.spec.ts`）**：

1. **举报**：`page.request.post('/api/public/reports')` 提交对 Alice 的 `artist_home` 举报（公开匿名入口，`ComplianceFooterLinks.vue:128` 走的就是它）。
2. **处理 + 下架**：`adminPage.request.post('/api/admin/artists/{aliceId}/home-takedown', {reason})` → 断言 `{success:true}`；再调一次断言 `{already:true}`（幂等，`ledger_P4.md` §9.2 第 1 条）。
3. **客户侧不可见**：`page.request.get('/api/artists/alice')` → 断言返回**最小载荷**（hidden 态：仅 id/name/subdomain/status，`isArtistHomeHidden` 生效）——**用 API 断言最小载荷，解耦 R2/W7 的文案口径**（不赌主页提示文案是否定稿）。
4. **恢复**：`adminPage.request.post('/api/admin/artists/{aliceId}/home-restore')` → 断言主页恢复可见（`page.request.get('/api/artists/alice')` 返回完整信息）。

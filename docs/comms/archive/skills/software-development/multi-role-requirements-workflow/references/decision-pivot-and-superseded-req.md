# 决策反转的落档套路（新方案替代旧方案）

> 来源：2026-08-05 QQBot 深聊批。用户聊到一半主动提出 TOTP（"扫码动态口令能引入吗"），直接推翻"QQ Bot 发登录码是上线门槛"的既有方向。
> 另含：批量深聊多话题的决策项挂账纪律、开源选型核实法。

## 触发信号

- 用户中途抛出与前文假设不同的方案/技术（往往是一句问句："XX 能引入吗？""有国产的吗？"）
- 用户批量回答决策项时漏答部分条目
- 用户一句话反转此前聊定的方向（"就用 X 做主方式，Y 我们之后加"）

## 流程（5 步）

1. **先核实再表态**：立刻读代码/查依赖验证可行性，给基于事实的结论。例：TOTP 核实 = 项目已有 crypto 模块、约 30 行可实现、零依赖零成本。**不凭印象附和，也不凭印象否定。**
2. **诚实讲全部代价**：新方案的每一处代价都要明说（首次绑定摩擦、丢失恢复路径、推翻哪些既有计划/排期）。用户拍板风格是"敲定，有问题再改"，但前提是你把问题先摆出来。
3. **呈现替代关系**：明确说清它替代了什么（"上线不再被 QQ Bot 卡脖子"），列 a) 新方案为主 b) 维持原方案 c) 两者都做 供拍板。
4. **拍板后双 REQ 落档**：
   - 新方向 → 新 REQ 编号（本例 REQ-027 TOTP，P0，承接原上线门槛）
   - 旧方向不删除 → 转**备案 REQ**（本例 REQ-028 消息网关，P2），把本轮聊定的所有细节（技术选型、托管方案、场景排序、风控约束、启动条件）固化进去，未来重启不用重聊
   - 编号先查：`rg -o "REQ-0\d\d" docs | sort -u` 防撞号（派工可能已预留某编号）
5. **传播清扫（决策变更传播规则）**：grep 所有引用旧方向的文档，全部同步更新后一次提交：
   ```
   rg -l "旧方向关键词1|关键词2" docs | sort -u
   ```
   本例清扫了：STATUS 待办池（L4 消解 + 上线前必做清单改写）、REQ-014（两处登录方式描述）。技术文档（开发→生产切换指南/CONTEXT.md 术语表）四号无权限 → 在需求稿"传播影响"表里点名转交一号/三号。

## 批量深聊模式（多话题一次派工）

- **先批量内部核实**：开工前把所有话题的代码现状一次读透，写成"现状实锤"人话交代给用户。技术选型结论必须实时核实，不凭记忆。
- **决策项一次全呈现**：每条附我的建议 + 理由，给 a/b/c 选项而非开放式问答。
- **未答项编号挂账、每轮重提**：用户批量回答经常漏项（答了 D1/D2 漏了 Q1）。编号 Q1/Q2/Q3 保持稳定不重排，每轮把未答项显式重新列出，直到拿到答案或用户明确跳过。静默丢弃未答项 = 事故。
- **每题落稿不攒批**：一个话题聊透就写一份需求稿；全部聊完统一转交。

## 开源选型核实法

推荐/否决开源方案前，用 GitHub API 查实时状态（stars、pushed_at、archived），不凭记忆：

```powershell
$d = Invoke-RestMethod -Uri "https://api.github.com/repos/OWNER/REPO" -Headers @{'User-Agent'='x'}
"{0} | archived={1} | pushed_at={2} | stars={3}" -f $d.full_name, $d.archived, $d.pushed_at, $d.stargazers_count
```

本例结论（2026-08-05，写入 REQ-028）：NapCatQQ 主选（活跃 10k star）；Lagrange.Core 备胎；go-cqhttp 实质停摆弃用；LLOneBot 依附桌面 QQ 不适用；NoneBot2 仅交互式场景需要（已排除）。

## TOTP 领域知识（REQ-027 沉淀）

- **零依赖实现**：Node 内置 crypto（HMAC-SHA1 + 30 秒时间窗 + 6 位截断），约 30 行，RFC 6238 标准算法，无需装包。
- **校验窗口**：±1 个时间步（前后 30 秒的码都算有效），容忍手机时钟漂移。
- **绑定流程**（管理员协助式）：后台生成密钥+二维码 → 画师手机 App 扫码 → 画师把当前码报给管理员 → 管理员后台验证 → 绑定成功。画师账号本就由管理员后台创建，流程自洽。
- **恢复方案**：只保留"管理员后台重置绑定"一条 + 服务器本机 CLI 兜底（可重置含管理员在内的任何账号，不经网络、只要求物理接触）。备用恢复码对小平台是过度设计，不做。
- **国内验证器 App 推荐**（写进画师引导文案）：
  - 微信小程序「腾讯身份验证器」——免装 App，但**能否扫第三方标准二维码待实测**（开发时生成测试码扫一下即知，不行就从清单移除）
  - 安卓：Aegis（开源，酷安下载）
  - iOS：2FAS 或微软 Authenticator（国内商店可下）
  - 不推荐 Google Authenticator（国内不可用）
- **关键收益话术**：TOTP 码在画师手机上生成，服务器与手机各持密钥独立算码，**全程不需要任何消息通道**——Bot 被封/断电/断网都不影响登录。这是它替代"QQ 发码"作为登录门槛解法的核心理由。

## 三、三路调研结论摘要（2026-08-25 子代理产出）

### 调研 A：开源桌面应用与等高对齐纪律
值得解剖的开源应用（均已核实）：Clash Verge Rev（Tauri+React+MUI，仪表盘等高行）/ Motrix Next（Tauri 2+Vue 3+Naive UI，与拾绘栈最接近）/ YesPlayMusic（Vue+Electron，网格严格对齐）/ Spacedrive / AFFiNE / UpScayl / Heynote。
**等高对齐纪律五条**：①全页 24 栅格按行分组，每行 1~4 盒，全局唯一 gap 值；②高度档位制（行高取 8 的倍数定档，禁止内容撑高）；③同行卡 `height:100%` + flex 纵列，标题顶锚/操作区 `margin-top:auto` 底锚；④卡内最多三层 + 文本 clamp + 定行数列表，装不下砍层级不加高；⑤分组靠留白不靠描边，重要性用位置不用样式。

### 调研 B：信息组织（视线与密度）
- NN/g 眼动：F 形视线，最重要信息左上；任务驱动型工具（Things/Linear/Toggl）走单列焦点流 + 自动排序。
- KPI 卡一屏 4~6 张封顶，每卡信息 3 层封顶；同决策语境的板块可合并（收入+统计→经营卡）。
- 逾期红色置顶是全行业惯例；倒计时用「相对天数文字 + 三色分级」最稳。
- **自定义真相**：NN/g 研究可定制首页反而降低控制感（iGoogle 已死）；Google 内部口径「默认值即答案，自定义只是兜底」；Things 零自定义成标杆。**建议：默认布局做强，只留显隐，砍自由拖排。**
- 建议架构：7 板块 → 4 区（顶部状态带 /「今日要办」单列流合并排期+账本且逾期置顶 / 经营卡（收入+统计）+留言 / 订单降为速览下钻）。

### 调研 C：三仓库源码解剖（可直接抄的 CSS 手法）
1. 多行网格等高：`grid + stretch + min-height 定档`（motrix TaskItem）
2. 封面定高：`aspect-ratio` 锁视觉大头（YesPlayMusic Cover）
3. 文字封顶：`-webkit-line-clamp` 钳行数（YesPlayMusic CoverRow）
4. 卡内上下锚定：`height:100%; flex-direction:column` + 中段 `flex:1`（clash-verge enhanced-card）
5. 空态垫层：绝对定位铺满不挡交互（motrix TaskView）
出处文件路径详见各仓库（已克隆本地）。

**已克隆仓库**：`temp/oss-desktop-research/{motrix-next, YesPlayMusic, clash-verge-rev}`（--depth 1，后续波次继续抄）。

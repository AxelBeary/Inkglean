## 一、产品与用户（30 秒版）

拾绘是画师接稿管理平台；桌面版（Windows，Tauri 2 壳）是画师的日常主入口。首页的使用场景是：**画师在 CSP/PS 里画着画，切过来瞥一眼——3 秒内知道「今天该干嘛、哪个快截稿、谁欠我钱、我画了多久」，然后切回去继续画。** 桌面端是伴侣不是主角，安静可靠，不抢注意力。

首页必须承载以下七项职能（组织方式完全自由，职能不可丢）：

| 职能 | 内容 | 语义 |
|---|---|---|
| 排期看板 | 进行中的委托 + 进度 + 截稿倒计时 | 时间压力一眼可读 |
| 账本待办 | 定金/尾款/待确认到账/今日待办 | 谁欠我钱、我该催谁 |
| 订单列表 | 近期订单状态速览 + 下钻入口 | 不占首页主体 |
| 收入概览 | 仅一行「本月已收 ¥X」 | 纪律：**钱不进日报**——无曲线无涨跌箭头，知道就好不用心跳 |
| 留言审核 | 客户留言待审数 + 入口 | 有事醒目、无事安静 |
| 统计卡 | 今日在画时长 + 摸鱼/离开占比 | 数据只存本地永不上传，界面语义要诚实 |
| 状态挂牌 | 开稿/休息一键切换（对客可见） | 唯一的仪式感动作 |

## 二、设计语言铁律（不可动摇，全部已用户拍板）

### 2.1 北极星与核心公式

视觉北极星：**纸艺山水**——米白手工纸折叠的立体山脉，水墨晕染，金线只勾山脊与亭台。用户原话：「自然、有美感、极为奢华但又很朴素」——细节爆炸且不简单，却看起来很平凡。

核心公式：**色彩与造型克制，材质与细节爆炸。**
- 色彩预算锁死颜料盘七色，**一枚新色都不许加**；
- 奢华预算全部花在「纸」上：纹理、厚度、光影、层次；
- AI 味的病根是反过来——颜色拼命喊、材质空空如也。

### 2.2 四条视觉规则

1. **金只点睛**：泥金只出现在三个时刻（完稿盖章/今日焦点/画师成就），平时全站无金，金出现 = 有喜事。首页日常态原则上无金。
2. **纸叠厚度**：卡片是「一叠纸」不是「悬浮盒子」——可见纸边厚度 + 克制的真实投影，与 SaaS 浮卡划清界限。
3. **墨分五色做层次**：分区优先用宣纸三阶底色与墨色四阶浓淡，**边框降级为偶尔为之**，严禁「边框治国」（v2 死因之一）。
4. **微型亭台**：空状态插画、小标记、加载小动作 = 山里的亭子——稀少、手工感、会心一笑；多了就成游乐园。

### 2.3 既有器物映射（可继承可演化，但别搞成古董店）

总规则：一件器物只许出现在一个模块；器物感只落在**一个结构 + 一个细节**上，其余全是纸；领不到器物的模块老老实实做纸面。检验标准：这个器物能不能帮画师一秒钟认出「我在哪个房间」？

- 排期 = **卷轴**（横向展开的手卷，两端轴头是唯一结构件）
- 待办 = **账本**（两类行：要画的无金额/要收的带金额右对齐淡墨；行间极淡墨线只横不竖；状态用一枚笔点：花青=进行中、朱砂=逾期（旁带极淡洇开）、石绿=已了；完成行不划线、变淡沉底）
- 留言 = **竹简**（一条留言一枚横简，窄长条两端微圆，简间留空隙不贴死，左侧细装订绳贯穿）
- 开关稿 = **挂牌**（店铺「营业中/今日闭店」翻牌，全后台唯一仪式感动作）

### 2.4 动效纪律

- hover **不做位移**，只做墨色加深一档（像指尖按在宣纸上微洇）；
- 容器静、文字动（内容浮现可以动，容器本身不弹不跳）；
- 挂牌翻转 = 唯一允许有仪式感的动作；
- 全程尊重 `prefers-reduced-motion`。

### 2.5 命名纪律

器物进形态，不进名字。界面文案一律平实：叫「待办」不叫「账本」、叫「留言」不叫「竹简」、挂牌就叫开稿/休息。

## 三、布局与信息架构的研究结论（强约束级别）

以下来自三路调研（开源桌面应用解剖 + 眼动/密度研究），请当作工程纪律执行：

1. **等高对齐**：同一行的卡片必须等高（grid stretch + 卡内 `height:100%` flex 纵列、标题顶锚/底部操作区 `margin-top:auto`）；行高定档（8 的倍数），**禁止内容撑高**；装不下就砍层级、文本 `line-clamp`、列表定行数，绝不加高。**「长长短短」是本项目最大的用户雷点。**
2. **视线有路线**：F 形，最重要的放左上。推荐骨架（可演化，不可散）：顶部状态带（挂牌+今日概览）→ 左上主焦点「今日要办」（排期+账本合并成单列流、逾期朱砂置顶、按截稿先后排）→ 右侧次级（经营卡=收入+时间、留言）→ 底部订单速览窄条。
3. **一屏密度**：可见区块 4~6 个封顶，每块信息 ≤3 层；逾期红置顶是行业惯例；倒计时用「相对天数文字 + 三色分级」（剩 3 天/明天截稿/逾期 2 天），别用大数字倒计时。
4. **默认布局即答案**：不做自由拖排，只保留「显示/隐藏」开关。
5. **间距**：全页唯一 gap 值（16~20px），分组靠留白不靠线；卡内禁止用外边距制造分隔。

## 四、三版失败原型尸检（反面教材，勿重蹈）

| 版本 | 做了什么 | 死因（用户原话） |
|---|---|---|
| v1 | 12 栅格 7 卡不等高 + 拖排 | 「长长短短的好丑」——卡片高度参差、视觉碎片化 |
| v2 | 等高对齐 + 5 区合并 + 纸墨色 | 「还是很丑加很敷衍」——只有排版没有质感，像毛坯样板间 |
| v3 | v2 + 宣纸噪点/垫纸错位/卷轴杆/印章角标/微旋转 | 「更是丑飞了」——小心思堆砌、每个元素都在抢戏、空位没补对 |

教训总结：**问题不在某一个技巧，而在没有统一的视觉世界观。** v2 缺魂（无材质无戏），v3 有戏但戏太多且各自为政。你的任务是建立一个**一个核心意象撑住全场**的世界，其余元素全部服从它。

用户历史痛点词库（设计时逐条自检）：「又方又圆」「大片空间浪费」「一条条像蛆」「长长短短」「敷衍」。

## 五、技术硬约束（原型必须满足）

1. **单文件 HTML**，自包含（CSS/JS 内联，外部仅允许上述字体 CDN）。
2. **必须声明浅色**：`<meta name="color-scheme" content="light">` + CSS `color-scheme: light`——预览环境会强制深色滤镜，不声明会被染黑（这是已踩过的坑）。
3. 响应区间 **800×600 → 1440×900**：默认按约 1180×780 的桌面窗口画，800×600 时不破版（可塌单列）。
4. 可交互：至少状态挂牌可翻、显隐开关可用、行/卡有 hover 墨色加深；`prefers-reduced-motion` 兜底。
5. 纯 HTML+CSS+原生 JS，不引框架不引组件库。
6. 演示数据用下方第六节的假数据，真实可信感（画师名/委托名/金额都要像真的）。

## 七、交付要求

1. **2~3 个方向**，方向之间必须是真的不同世界观（不是换色换间距）：
   - 每个方向给一句「世界观陈述」（这个首页像什么）；
   - 每个方向一个单文件 HTML，命名 `proto-desktop-home-r2-A/B/C.html`；
   - 每个方向附 300 字内设计说明：核心意象、信息层级决策、器物用法、为什么这样治了第四节的病。
2. 方向种子（仅供参考，可以推翻自立）：
   - A「案头长卷」：整页是一幅徐徐展开的手卷，信息沿卷轴流；
   - B「账房桌面」：俯视的书案，账本/便签/挂牌各居其位，材质为王；
   - C「纸窗一格」：极简现代骨架 + 纸墨材质细节，效率优先到极致。
3. 完成度要求：**高保真**——纹理、纸边、字阶、笔点、空态全部做出来；不接受线框感、占位灰块、「骨架批占位」字样。
4. 自检清单（交稿前逐条过）：等高对齐了吗？三秒能读出今日要务吗？有一枚新色吗（不许）？有一个元素在抢戏吗（砍）？800×600 塌吗？深色滤镜防了吗？

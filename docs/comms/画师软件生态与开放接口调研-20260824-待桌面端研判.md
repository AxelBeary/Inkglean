## 二、开放接口成熟度总榜（0-10）

### 第一梯队：具备深度集成条件

| 软件/平台 | 分数 | 接口形态与关键点 |
|---|---|---|
| **Eagle** | 9.4 | 本地 HTTP REST（`localhost:41595/api/v2`，需 Eagle 4.0 Build 21+）；素材/标签/文件夹/标签组增删改查、全文+AI 语义搜索、图片区域批注；本机免鉴权、局域网需 token（偏好设置→开发者）；另有 JS Plugin API；已支持 MCP 生态；文档提供 `llms.txt` 与 API Playground。**坑：必须客户端运行中；删除为软删除；部分端点绑定较新 build，集成前先探 `/api/v2/app/info`** |
| **Blender** | 9.8 | 完整内嵌 Python API（bpy/bmesh），支持 `--background --python` 无头批处理渲染参考图；VRM Add-on 可脚本化 |
| **Photoshop** | 9.6 | ExtendScript（JSX）/ CEP / UXP 三代体系 + 8BF 插件 + Action 批处理；UXP 为现代异步方案 |
| **Ko-fi** | 8.5 | **约稿单/商店订单/捐赠/订阅实时 Webhook**，免费零门槛；无拉取型 API，历史订单靠 CSV 导出补录 |
| **ComfyUI** | 8.8 | 工作流即 API（POST /prompt），WebSocket 实时进度；原生无鉴权，暴露公网需自建反代 |
| **SD WebUI (A1111)** | 8.8 | `/sdapi/v1` REST，`--api` 开启，自带 Swagger；社区客户端库成熟（webuiapi） |
| **Patreon** | 8.0 | OAuth2 + 官方 Webhook，可读赞助人/档位/付费状态/历史金额（JSON:API） |
| **Krita** | 7.9 | 开源唯一全功能 Python 脚本 API（LibKis），可做 PyQt 面板插件 |
| **爱发电** | 7.3 | 国内唯一正规赞助/订单开放 API（query-sponsor/query-order，MD5 签名，轮询式，无 webhook）；只读 |
| **Notion / Trello / Google Calendar** | 9.5+ | 官方 API 成熟，排单表双向同步/交稿提醒写入零障碍 |
| **Bluesky**（海外） | 9.3 | AT Protocol 免费公开端点，App Password 即可认证，约 100 次/分钟限流 |

### 第三梯队：死墙（完全封闭，但恰是画师高频使用的）

| 软件/平台 | 现状 |
|---|---|
| **米画师、画加（网易）** | 国内约稿交易头部平台，零开放平台、零开发者入口；爬虫有合规风险 |
| **Procreate** | 无官方 API；手册里的 "Actions" 只是应用内菜单不是编程接口；仅系统级拖放/导入导出 |
| **Clip Studio Paint** | 无脚本；仅受限单图层滤镜插件（TriglavPluginCall，.cpm，仅 EX 版，SDK 仅日文）；业界惯例是存 PSD 后绕道 PS 处理 |
| **SAI/SAI2、ibisPaint** | 零插件零脚本；工程文件私有二进制 |
| **VGen** | 海外最大约稿平台，无开发者计划，ToS 明令禁止抓取 |
| **Pixiv / pixiv FANBOX** | 无官方开放 API；社区全是逆向库（PixivPy 等），随时失效 |
| **微博（个人开发）** | 开放平台名义存在，读接口实质关闭，发布需企业资质 |
| **微信（个人）** | 零官方接口，所有"个人微信 API"均为逆向灰产 |
| PureRef、Billfish、Midjourney、Coolors、Adobe Color、DesignDoll、Magic Poser、Affinity Photo（仅宏）、MediBang（仅 Lua 笔刷脚本）、花瓣/堆糖 | 均无可用开放接口 |

## 三、对本平台（约稿管理系统）的战略结论

1. **Eagle 是全生态唯一"高渗透 + 现代 API + 中文生态 + 拥抱 MCP"的交集**，是素材管理自动化的天然落点。典型集成场景：约稿立项/参考图/交付稿自动同步进画师 Eagle 素材库（建「约稿-单号」文件夹 + 打标签 + 写注释）。集成前置探测 `/api/v2/app/info` 判断版本；大库场景用 `fields` 参数控响应体积。
2. **订单导入管道**：海外首选 Ko-fi Webhook（实时推新约稿单，历史单 CSV 补录）+ Patreon（金主画像）；国内唯一正规来源是爱发电（轮询同步）。
3. **创作软件层不硬碰**：CSP/Procreate/SAI 用户占大头但全是死墙，只做"交付文件层"（PSD/PNG 导入）；深度自动化只留给 Photoshop（UXP）与 Krita（Python）用户。
4. **国内沟通/交易环节是死结**：微信零接口、米画师/画加零接口——产品只能做"外围中枢"（订单提醒、稿件状态、赞助通知），引导画师手动确认，不指望打通聊天与交易层。
5. **竞品信号**：海外 Commission Hero（约稿队列/进度追踪，无 API）产品形态与本项目高度重合，建议列入产品对标观察名单。
6. **桌面端研判视角补充**：Eagle/SD WebUI/ComfyUI/Blender 的接口均为**本地服务**，与桌面端"本地优先"架构天然同构——若桌面端接入，天然规避服务器侧凭证/代理问题，与既有安全三口径无冲突。

## 四、可信度与待复核清单

- X API 定价、Bluesky 限流、爱发电字段定义：多来源一致，可信度高。
- **立项前建议人工复核三处**：① Ko-fi webhook 后台事件字段与 token 路径；② Patreon webhook 事件清单；③ 爱发电 dev 后台当前接口列表。
- Midjourney 2026 年出现 alpha 版/文档域名迹象（未普惠），按"未公开"处理并建议持续跟踪。
- 米画师/画加"无开放平台"为全公开资料检索结论，不排除存在未公开的企业合作通道。

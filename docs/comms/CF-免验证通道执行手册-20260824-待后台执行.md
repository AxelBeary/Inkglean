# CF 免验证通道执行手册（桌面端登录类接口）

> **状态：待用户/管理员在 Cloudflare 后台执行**（本地无 CF 凭证，代理侧无法代操作）。
> 依据：REQ-014 安全口径二（2026-08-24 拍板）——「只免登录类接口，不整站放行；桌面端身份标签仅分流统计，落档写死可伪造、非防线」。
> 配套：桌面登录接口已于 824 落地（`desktop/docs/STATUS.md` 顶部最新条，迁移 v73）。

---

## 一、要解决什么

画师日常入口转向桌面端后，登录请求若撞上 Cloudflare 验证页（质询），桌面应用**没法像人一样点验证**，登录直接卡死。解法：对「登录类接口」这一小撮路径免验证放行，其余整站防护原样不动。

## 二、放行范围（已对照代码核实，宁窄勿宽）

桌面端首发只走 TOTP 登录，真正需要的无凭证接口只有 4 个：

| 方法 | 路径 | 用途 |
|------|------|------|
| POST | `/api/auth/verify` | 网页/桌面共用 TOTP 登录 |
| POST | `/api/auth/desktop/login` | 桌面端登录（记账式会话，824 新增） |
| POST | `/api/auth/webauthn/login-options` | Passkey 登录取质询（二期备案，先备好） |
| POST | `/api/auth/webauthn/login-verify` | Passkey 登录验证（二期备案，先备好） |

**明确不放行的**：邀请注册流（/api/invite/*，浏览器注册场景人工过验证无碍）、一切登录态接口（带 token 的请求本就少触发质询）、一切客户侧接口。

## 三、执行步骤（CF 后台）

1. **先诊断质询来源**：Security → Events，翻最近的 Challenge/Managed Challenge 事件，看是哪类规则触发的（Bot Fight Mode / 托管规则 / 自定义规则 / 安全等级）。**放行规则必须针对触发源设置跳过，否则不生效。**
2. **建放行规则**：Security → WAF → Custom rules → Create rule：
   - 名称：`desktop-login-channel`（免验证通道·登录类接口）
   - 表达式（可直接粘贴）：

   ```
   (http.request.uri.path eq "/api/auth/verify")
   or (http.request.uri.path eq "/api/auth/desktop/login")
   or (http.request.uri.path eq "/api/auth/webauthn/login-options")
   or (http.request.uri.path eq "/api/auth/webauthn/login-verify")
   ```

   - 动作：**Skip**。跳过的组件按第 1 步诊断结果勾选——触发源是哪类就跳过哪类（常见组合：All remaining custom rules + All managed rules；若质询来自 Bot Fight Mode 则须勾 Bot Fight Mode）。
   - 顺序：放在其他自定义规则**最前**。
3. **不建第二个规则**：身份标签不做放行条件（见下）。

## 四、身份标签口径（落档写死）

- 约定：桌面端未来所有 API 请求带头 `X-Shihui-Client: desktop/<版本号>`（桌面端 HTTP 层接线批落地）。
- **写死：该标签可伪造、仅用于分流与统计，不是安全关卡，不作为任何放行/拒绝条件。** 真正防线=应用层三道门（登录限流 10 次/5 分、错 5 次锁 15 分、TOTP 重放防护）+ AOP 源站认证（TLS 层，不动）。
- 放行规则用**路径**而非标签做条件：标签伪造零成本，拿它当门禁只会误伤自己。

## 五、验收方法

1. 桌面壳登录页上线后走真实登录（当前可先用等价模拟：带桌面 UA 连打 3 次 `/api/auth/verify`，观察是否还弹质询）。
2. CF Events 里过滤这 4 条路径，应显示 Skip 命中、无 Challenge。
3. 反向验证「没放太宽」：随便一条非登录路径（如 `/api/health` 之外的客户接口）保持原防护行为不变。

## 六、顺带提醒（不属于本项，登记备查）

- **CORS**：桌面壳请求的 origin 是 tauri 壳的本地 origin，生产 `CORS_ORIGIN` 白名单届时需补——属「桌面端接线批」任务，别在本项里顺手改。
- 本手册执行完成后：勾选 `desktop/docs/STATUS.md` 开工清单「CF 规则调整」项，并把实际触发源与规则截图要点回记一条。

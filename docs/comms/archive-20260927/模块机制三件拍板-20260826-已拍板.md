## 拍板一：视图字段清单附件（规范 §八-1）

**结论：四视图 + 敏感字段默认剔除联系方式。**

| 视图 | 来源 | 字段 | 剔除 |
|---|---|---|---|
| `orders` | 云端 | order_no / client_name / tier_name / status / deadline / total_price_cents | client_qq 等一切联系方式 |
| `ledger` | 本地 | client_name / title / price / deadline / status | 同上（本地记账无联系方式字段，纪律一致） |
| `time` | 本地 | 按日：date / paint_secs / idle_secs / other_secs；归单：order_id / total_secs | — |
| `messages` | 云端 | nickname / content / created_at / status | 留言者联系方式类字段 |

**敏感字段口径**：一切 `*_qq` / 手机号 / 邮箱 / token 类字段默认剔除；客户名保留（模块文案需要，如「稿情气象台」报单名）。视图来源标签（本地/云端）随壳层模式过滤（规范审计 H5 既有纪律）。

## 拍板二：违规阈值、统计窗口与私有存储配额（规范 §八-2）

**结论：10 次 · 24h · 5MB · 5s×3（保守口径，参考浏览器扩展）。**

| 项 | 数字 | 行为 |
|---|---|---|
| 违规阈值 | 10 次 | 达阈 → 该模块单独停用 |
| 统计窗口 | 24 小时滚动 | 24 小时无新违规则计数自动清零；手动重新启用也清零（防死状态，规范既有） |
| 私有存储配额 | 5MB / 模块 | 超配额＝拒写 + 记一次违规（不停用）；存储独立文件、不入 data.db、不进导出包（规范审计 M7 既有） |
| 心跳 | 5 秒一拍，失联 3 次 | 杀帧置灰牌（可重试一次，再崩转停用，四态纪律既有） |

## 拍板三：沙箱帧载体（规范 §八-3）

**结论：默认 A（跨源沙箱 iframe）；B（独立 Webview）作例外逃生门＝「留门不实现」口径。**

- **A 定案形状**：模块渲染于 `asset.localhost` 独立 origin 的 iframe，`sandbox="allow-scripts"` 最小化（禁 allow-same-origin / top-navigation / forms / popups / modals），帧级 CSP：`default-src 'none'; script-src 'unsafe-inline'; connect-src 'none'; img-src data: blob:; style-src 'unsafe-inline'; worker-src 'none'; base-uri 'none'; form-action 'none'; frame-src 'none'`。
- **B 定位**：独立 Webview 进程隔离更强，但与「模块即板块」长卷内嵌形态冲突（只能另开浮窗）、跨窗心跳复杂——首发不实现，规范留门字段，未来极高危/需独立生命周期模块再开。
- **落地验收项（第三方研判采纳）**：施工完成后实测模块帧是否独立 renderer 进程（WebView2 跨源站点隔离为 Chromium 默认行为，无需实验开关，但须实测确认）；若 opaque origin iframe 无法稳定独立进程，高危模块切 B。
- **消息信封（第三方研判采纳入规范）**：桥消息一律 `{ id, type, payload, token }` 信封；壳校验 event.origin（opaque origin 为 null）+ event.source 与注册帧一致 + type 白名单，未知类型丢弃并记违规。
- **加载超时（第三方研判采纳入规范）**：模块初始化 5 秒超时 → 灰牌占位，不阻塞首页。

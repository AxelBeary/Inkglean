## 二、两难（这就是 W7 必须你拍板的根因）

- **改中性「暂时无法访问」**：真·自隐身画师**失去「去设置开启」的自助指引**（他主动关的，文案却不再告诉他怎么开）。
- **不改（保持现状）**：被平台下架的画师看到**错误的自助指引**（"请到设置开启"——但他开了也没用，平台下架自助不可解，见 `ledger_P4.md` §9.4 第 3 条），更困惑挫败。

## 三、方案 + 强推荐

- **方案 A（兼顾文案，🔵 强推荐）**：主页提示改为中性 + 双指引，例如「该主页当前不可访问。若你是店主且主动关闭了展示，可到「设置 → 主页展示」重新开启；若主页是被平台下架，请在你的后台查看原因与指引。」
  - **三维理由**：① 工程学——纯文案改动（zh-CN.ts:844 + en.ts:845 中英同步），不动组件、不动后端同载荷设计；② 社会学——被下架画师的困惑（"我明明开了怎么还隐藏"）比自隐身画师更重（后者自己关的、知道怎么开），兼顾文案给两类人各自出路；③ 直觉——诚实、不误导任何一方。
  - **✅ 呼应闭环已从"设想"变"成立"**：R1 本轮**已落地 W4 画师后台下架横幅**（`ArtistLayout.vue` + 新建 `homeTakedown` locale 区，显示下架原因 + "联系平台管理员申请恢复"）。方案 A 的"若被平台下架请在后台查看原因"现在有了**真实承接**——访客侧主页提示 → 画师侧后台横幅，形成闭环，不再是空指引。
  - **代价**：文案略长；且向公开端访客**暗示了"存在平台下架机制"**（若你认为不宜对访客暴露此信息，则选 B）。
- **方案 B（纯中性）**：「该主页暂时无法访问。」——简洁、不暗示下架机制；代价＝自隐身画师也失去自助指引（但他知道自己关的，影响较小）。
- **方案 C（不改）**：保持现状；代价＝被下架画师看到错误的自助指引（开了没用）。**不推荐**（对被下架画师不诚实）。

**推荐结论**：**方案 A**（如你认为不宜对访客暗示下架机制，退而选 B）。**这是推荐、不是已成立的决定**——你点头前 W7 不落地。

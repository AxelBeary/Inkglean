### 🐛 修复（均带回归）

- **管理员强制删留言失效**：删除本身成功（软删），但管理端/画师端留言列表查询漏过滤 deleted_by_admin，刷新即回显；两查询补过滤（COUNT 同口径防分页错位），物理行留痕不动。
- **统计导航首载闪现**：后台开关关闭时，刷新后资料加载前的空窗期统计导航先显后隐；改「未知=未开」隐藏（统计默认关），布局预拉资料缩短空窗。
- **公告长文撑爆弹窗**：公告弹窗内容区限高内滚，不再挤出屏幕。
- **焦点图工具条不随字号缩放**：排期看板「焦点图显示」说明文字补字号缩放；同时按用户反馈把「关/大」两态滑块改成开关（语义不变）。

### ✨ 新功能

- **已移除画师清单 + 恢复**（用户拍板）：移除画师本是软删但无任何入口可见；管理端画师管理页新增「已移除画师」弹窗（清单+两步确认恢复）；恢复后需重新登录，封禁态不受恢复影响；子域名/QQ 占位冲突由表级约束物理保证。
- **系统更新检查面板**（用户拍板方案 A）：管理端系统自检页新增只读卡片——当前版本（版本号/提交/部署时间）vs GitHub master 最新 commit，三态结果（已是最新/可更新/无法对比）+ 更新命令一键复制；部署脚本同步写入版本标记；后端拉取带 15 分钟缓存与降级（GitHub 不可达不报错）。真自更新方案（挂 docker.sock）因安全风险明确否决。

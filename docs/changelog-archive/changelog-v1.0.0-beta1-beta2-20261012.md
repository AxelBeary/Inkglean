## v1.0.0-beta.2 审计修复收口版（2026-08-15）

> 815 两轮深度审计（P0=0）修复全量收口 + 用户亲裁 12 项拍板全部落地 + 剩余销账轮（P1 剩 5 项 + 低危六路并行清零）；终态基线 server 1462→1521 / web 540→545 / E2E 11→13，迁移链 v64→v66。

### 🔧 剩余销账轮（继首批后的第二轮，P1 全部销账）

- **P1-3 乐观锁前端全面接线**：useOrderWorkflow/DeliverDialog/QueueBoardList/OrderDetail/ExtraItemsPanel 写请求携带 version，409 ORDER_CONFLICT 冲突提示 + 重拉服务端真相，双开标签页改价不再静默互覆（common.orderConflict 双语）。
- **P1-5 向导/邀请码 TOTP 确认防爆破**：setup 与 invite 确认路径对齐登录口径（连错 5 次锁 15 分钟，锁定期正确码也拒），回归 3 条。
- **P1-7 原生部署 Sentry 配置**：vite envDir 钉仓库根，根 .env 的 VITE_SENTRY_DSN 构建时可读了。
- **P1-8 双库分裂根治**：dotenv 与 DB 默认路径按文件位置推导仓库根（6 处收口），从任意目录启动不再开出第二套库；server/data 遗留库隔离至 data/quarantine/。
- **P1-10 e2e 补两链**：E9 邀请码注册链（生成码→注册→TOTP 首绑→会话生效→码核销）+ E10 上传交付与一次性下载链（下单→上传→交付→下载锁定→410→再许可）。
- **低危六路并行清零（codex）**：K1 客户端杂修 11 项（串单守卫/剪贴板分离/计价错误态/参考图常量/埋点哨兵等）；K2 画师/管理端 11 项（带款取消二次确认/批量上传隔离/回滚基准/算价器错误态等）；L 服务端 13 项（deleteStage 守卫/regenerate-token 版本守卫/优先级终态守卫/seed 生产守卫/schema 基线对齐 v64/cookie 弱默认移除等）；M 三域消毒（order/style/compliance 文本字段分档消毒入库 + OG 投毒面关闭，回归 17 条）；N 测试加固与清理（弱断言收紧/垃圾清理）；P N+1 批量化（公开画廊与 admin 订单列表批量预取，契约不变）。
- **连环适配修复**：L-8 step-up 兜底守卫回归修正（告警暴露接线问题但纵深防御不削弱）；e2e seed/测试服务器显式 NODE_ENV=test（防生产守卫与 secure cookie 连环坑）。

### ✨ 拍板新功能

- **取消 5 秒撤销**：订单取消后右下角倒计时撤销条（详情页 + 队列看板）；窗口存后端数据库刷新不丢；窗口内队列重排/递补延迟执行，只撤最近一次并留痕；启动时扫描补结算（迁移 v65）。
- **交付文件一次性下载**：客户凭查单令牌完整下载一次后自动锁定（IP/时间留痕供纠纷取证）；下载器场景 60 秒兜底；半途下载 3 次防护锁定 + 5 分钟冷却；画师可「再许可」；交付文件拒绝分段下载；隐私政策披露 IP 收集（迁移 v66）。
- **系统增项模板管理**：管理端新增系统模板（商业用途/加急等）增删改入口（step-up 守卫）；改价可选「冻结旧价」或「全平台同步」；删除带引用计数提示。
- **安装口令升级**：SETUP_TOKEN 32 位升 128 位，安装完成打印直达链接 /setup?token=xxx 免手输；硬约束核实口令仅用于向导鉴权。
- **向导物理销毁**：初始化完成后 /setup 路由移除、后端接口 410；系统重置后自动回归。
- **封禁与解封**：封禁升级两步确认（对齐转账级）；新增解封入口（画师管理/举报页，对称两步）。
- **备份三档分层**：每日留 7 份 / 部署前留 2 份 / 每周留 4 份；分档轮转不跨档误删；rollback 支持 -Tier 选项。

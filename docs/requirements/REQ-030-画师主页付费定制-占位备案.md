## 三、兼容性核实（四号 2026-08-05 代码实锤——地基已全部就位）

| 能力 | 现有基础设施 | 结论 |
|------|--------------|------|
| 拉取画师数据 | `GET /api/artists/:subdomain` + `GET /api/public/pricing/:subdomain`（公开 API，无需登录） | ✅ 定制页 JS 直接 fetch |
| 引用后台图片 | 作品/档位示例/画风封面/头像均为 `/uploads/` 公开静态直链（fastifyStatic，app.js L187） | ✅ `<img>` 直接引用 |
| 对接约稿下单 | `/artist/:subdomain/order` 独立下单路由 | ✅ 定制页按钮跳转即可，订单走标准流程 |
| embed tab | Settings.vue 已有占位（P0-5 后 disabled） | ✅ UI 占位在 |

**唯一技术坑**：跨域（CORS）。定制页若部署在平台域名之外，JS 调公开 API 需 CORS 白名单支持（现只配平台自身域名）。两条路：a) 定制页托管在平台域名下（无跨域问题）；b) 外部部署则需三号加 CORS 白名单机制。部署形态待未来规划时定。

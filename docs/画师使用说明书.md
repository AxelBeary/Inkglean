# 🎨 画师使用说明书

> 这份说明书面向使用本平台的画师。不需要任何代码知识，会用手机/电脑上网就行。
> 最后更新：2026-08-18（正文主体为 v0.46 时代写法，新功能请看下方速览）

## 🆕 近期新功能速览（2026-08 中下旬，正文未及覆盖）

- **取消订单可反悔**：取消订单后右下角有 5 秒倒计时撤销条，点一下就能撤回这次取消。
- **新手导览**：第一次进仪表盘会自动弹出分步指引（12 步）；以后想再看，仪表盘右上角卡片里随时重开。
- **再来一单**：订单详情页有「再来一单」按钮，老订单的描述/款式/备注（可勾选参考图）一键回填到录单页。
- **偏好设置重排**：设置页顶部改成三个标签页（通用 / 显示与字号 / 快捷入口）；字号改成拖动条（14~20 像素）、新增动画速度调节（0.5~2 倍）与「减少动效」开关。
- **排期看板换标签页**：看板 / 月历 / 时间条改成顶部标签页切换，切来切去不再丢月份和滚动位置；「焦点图显示」改成开关。
- **留言可手动关闭**：设置页基本资料里有留言开关，关闭后客户主页的留言板块隐藏、也不再收新留言（历史留言不删）。
- **交付文件一次性下载**：客户下载交付文件只能完整下载一次（防转发），你可以根据需要「再许可」一次。
- **管理端新增**（管理员才看得到）：已移除画师清单与恢复、系统更新检查面板、统计总开关。

## 一、平台首页

打开平台网址，你会看到 **所有画师的列表页**，展示每位画师的头像、昵称、简介和当前状态（可约稿/已排满/休息中）。

点击任意画师卡片，即可进入该画师的个人主页。

---

## 二、登录后台

> 从 v0.37 起，登录方式改为 **TOTP 动态口令**：手机验证器 App 上每 30 秒刷新一次的 6 位数字，替代旧的 QQ 收验证码。全程不依赖 QQ 消息。

### 第一步：绑定动态口令（首次使用，需管理员协助）

1. 把你的 **QQ 号** 告诉管理员，由管理员在管理后台为你创建账号
2. 管理员会展示一个 **二维码**，用手机验证器 App 扫码（推荐：腾讯身份验证器 / Aegis / 2FAS）
3. 扫码后 App 里出现你的账号，把 App 上当前显示的 **6 位动态码** 报给管理员
4. 管理员输入确认后，你的账号就绑定好了

### 第二步：日常登录

1. 打开平台网址，在浏览器地址栏末尾加上 `/login`（如 `平台域名.com/login`），进入画师登录页
2. 输入你的 **QQ号** + 验证器 App 上当前的 **6 位动态码**
3. 点「登录」，登录成功后 7 天内免重复登录

> ⚠️ 动态码输错 5 次会锁定 15 分钟，别慌，等一会儿再试。
> ⚠️ 换手机/手机丢了：找管理员点「重新绑定」生成新二维码，重新扫码绑定即可；旧手机上的绑定立即失效。

## 三、设置你的主页

登录后进入 **主页设置**（侧边栏「门面」分组），页面分为三个标签页：

### 基本资料

| 设置项 | 说明 |
|--------|------|
| 头像 | 点击上传头像，客户主页和后台侧边栏都会显示 |
| 画师昵称 | 客户看到的名字 |
| 身份码 | 订单号前缀（如 `ALICE`），2-20位大写字母/数字，默认自动生成 |
| 个人简介 | 一两句话介绍自己 |
| 联系QQ | 客户在查询页看到的联系QQ（留空默认用登录QQ），解决换号/多号问题 |

### 主页展示

| 设置项 | 说明 |
|--------|------|
| 主页公告 | 一条短公告，客户主页首屏醒目展示，可设过期时间自动消失（如"本周休息，下周一恢复接单"） |
| 链接 | 最多 **8 条** 社交/平台链接，在主页展示。**粘贴完整网址**即可，粘贴后自动识别平台（微博/B站/P站等）并点亮对应图标；忘了写 `https://` 也会自动补上；识别不出的归为「其他」通用图标 |
| 灵感标签 | 最多 20 个，客户下单时可点选快速填入描述 |
| 须知编辑 | 就在这个标签页下方的独立卡片里（见第六节） |

### 模板与风格

在这里选择客户主页的布局和配色（见第十五节），还可以设置强调色（客户主页按钮/链接的颜色）。

> 💡 **接稿状态**（可约稿/已排满/休息中）现在在 **开稿管理** 页面设置，不在主页设置里了（见第九节末尾说明）。
> 💡 **偏好设置**（客户QQ通知开关、仪表盘默认面板、快捷按钮）拆到了侧边栏「门面」分组的独立页面 **偏好设置**。

## 四、管理画风与价格

进入 **价格管理**（侧边栏「经营」分组）。

> 💡 **概念更新**：从 v0.35 起，"档位"不再是独立概念。价格按 **画风 × 尺寸** 组织——每个画风下挂自己的尺寸列表，尺寸就相当于原来的档位（如头像/半身像/全身像），每个尺寸有自己的价格。客户看到的是"选画风 → 选尺寸"的两层价目。

### 画风与价格（默认标签页）

1. 点 **"+ 新建画风"**，填写：
   - **画风名称**：如"日系"、"厚涂"、"像素风"
   - **描述**（可选）：适合什么风格、什么场景
   - **示例图**（可选）：上传一张代表该画风的图
   - 可以勾选"从增项库一键导入"，把增项库里的增项自动带进这个画风
2. 在画风下 **添加尺寸**，每个尺寸填写：
   - **尺寸名**：如"头像"、"半身"、"全身"
   - **基础价**：单位元
   - **尺寸图**（可选）：直接上传新图，或从你的作品集里挑一张
   - **描述**（可选）：这个尺寸包含什么、适合什么
   - **工期**（可选）：大概几天能画完
3. 尺寸和画风都可以 **拖拽排序**，客户主页按你排的顺序展示

客户在你的主页上会看到按画风分组的价格表，带尺寸图的展示效果更好。

> 💡 可以随时编辑或删除画风/尺寸，不影响已有订单。尺寸图也可以随时更换或移除（不设置时客户会看到画风示例图兜底）。

### 多画风开关

价格管理页顶部有 **多画风** 开关：
- **关闭**（默认）：客户端只显示你的默认画风（排序最前的启用画风），其他画风保留但暂时对客户不可见
- **开启**：所有启用的画风对客户可见，客户下单时可自由切换画风

> 💡 如果你只经营一种画风，保持关闭即可，客户看到的和以前一样。

### 增项库

价格管理里的 **增项库** 标签页是增项的唯一来源。先在增项库里创建增项模板（如"表情差分 +30元/个"、"加背景 +50元"），再导入到各画风使用。增项支持三种控件：开关、数量、单选，计价支持固定价、单价×数量、选项价。

### 倍率

价格管理里的 **倍率** 标签页和以前一样：如"商用 ×2"、"加急 ×1.5"。客户下单时选择倍率，系统自动计算总价。

## 五、上传作品

进入 **作品管理**（侧边栏「经营」分组）：

1. 把图片文件 **拖进上传区域**，或点击选择文件，或 **Ctrl+V 粘贴截图**
2. 支持 JPG / PNG / WebP 格式
3. 上传后自动显示在主页的作品展示区
4. **封面星标**：点图片右上角的 ☆ 可把作品标为封面（★），客户主页首屏轮播展示封面图；可以多张共存
5. **多选删除**：点"管理"进入多选模式，可以批量删除作品
6. 封面图（主图）会单独展示在页面顶部，不和下方网格里的作品重复

> 💡 除了手动上传，**已交付订单的完稿图也可以直接"发布为作品"**，自动进入作品展示区（见第十一节）。

## 六、编辑约稿须知

进入 **主页设置 → 主页展示** 标签页，页面下方有独立的 **须知编辑** 卡片：

- 写清楚：不画什么、修改规则、工期说明、版权说明等
- 支持简单的 HTML 标签（`<h3>`标题、`<ul><li>`列表、`<strong>`加粗）
- 下方有实时预览
- 客户下单时 **必须滚动阅读并勾选同意** 才能提交
- 须知单独保存，不和主页其他设置混在一起

## 七、处理订单

### 方式一：客户自助下单
客户在你的主页填表提交后，订单自动进入你的队列。

### 方式二：手动录单（客户只通过QQ联系时）
进入侧边栏「工作」分组的 **手动录单**（全屏页面，左右两栏）：

**左栏"客户说了什么"**：
1. 填写客户QQ号（输入后自动查询该客户的历史订单）、昵称
2. 粘贴需求描述（从QQ聊天复制）
3. 选择优先级（默认"中"）、截稿日（可选）
4. **上传参考图**：客户在QQ发给你的参考图，直接拖进来或 Ctrl+V 粘贴（最多 5 张，录单后仍可在订单图库补充，合计上限 20 张）

**右栏"怎么录"**：
1. **选画风 → 选尺寸 → 勾增项**（和客户自助下单一样的三级选择，价格实时计算；只经营一个画风时自动跳过选画风）
   - 也可以什么都不选，直接填最终价格录一单"自定义单"（不选也能手输价）
2. **最终价格**：默认自动跟随系统计算价——只要你不手动改过，选画风、加增项、换倍率后价格都会实时跟着算；一旦你手动输入了金额，系统就尊重你填的数字，不再自动覆盖
3. **开稿日**（可选）、**初始节点状态**（线下已谈好的单子可直接跳过确认环节）
4. **QQ通知开关**：是否允许客户接收QQ排队提醒
5. 点"录入订单" → 生成订单号，自动进入排期

> 两种方式录入的订单进同一个队列，管理方式完全一样。

## 八、流程与收款比例

进入 **价格管理 → 流程与比例** 标签页：

### 流程节点
- 系统默认提供 7 个节点：定稿 → 排期确认 → 草稿确认 → 线稿确认 → 上色确认 → 完稿确认 → 交付
- 你可以 **添加/删除/改名** 节点（至少保留 1 个）
- **拖拽排序**：拖动节点调整顺序，最后一个收款节点自动成为"尾款"

### 收款比例
- 打开节点的"收款"开关，该节点变为收款节点
- 用 **比例条** 拖拽调节各收款节点的百分比（Q弹动画反馈）
- **向右拖拽**可吞并节点（关闭该期收款），向左拖到底也可移除
- 尾款比例自动计算 = 100% − 其他收款节点之和
- 限制：最多 20 个收款节点，每个最低 5%，尾款不可删除/关闭

### 节点说明
- 点击节点名称可改名
- 点击灰色说明文字可为该阶段添加描述（如"双方确认稿件需求与规格"）

### 修改次数告示
- 在流程管理页面可以写一段 **修改次数说明**（如"每阶段含 2 次免费修改，超出按 50 元/次收取"）
- 这段文字会显示在客户看到的流程预览中，让客户下单前就知道修改规则

### 恢复默认
- 底部有"恢复默认模板"按钮，点击后确认即可重置为出厂 7 节点流程
- ⚠️ 此操作会覆盖你当前的所有自定义节点和比例，无法撤销

### 使用说明
- 流程节点标题旁有"使用说明"按钮，点击弹出详细操作指南

### 客户看到什么
客户在你的主页价格板块和下单页能看到流程预览条（含修改次数告示），了解整个约稿步骤和付款节点。

## 九、排期看板

进入 **排期看板**（侧边栏「工作」分组），页面有三种视图，顶部切换：

### 看板视图（默认）

- 所有活跃订单按 **优先级（高→中→低）+ 下单时间** 排列
- **拖拽卡片** 可以调整顺序：
  - 拖动后整个队列顺序更新，后端按新顺序重新分配排队位置
  - 优先级不会因拖拽改变（优先级通过订单详情页单独设置）
  - 例：把第 5 张卡片拖到第 2 位 → 它变成第 2 位，原来的 2-4 位依次后移
- 每张卡片上有快捷操作按钮：确认 / 开始制作 / 完成 / 交付 / 取消
- 走到最后一个流程节点的订单，卡片上显示 **「去交付」**，点击直接弹出交付窗口
- **交付防手滑**：所有「交付」操作（含已完成订单卡片上的快捷按钮）都会弹出交付窗口确认后再标记已交付，不会一键直接改状态
- **焦点图**：如果订单设置了焦点图，卡片上会直接显示角色缩略图，一眼看出这单画什么
- 名额满了之后，新订单进入 **缓冲区** 候补（独立标签页），有名额空出时可一键递补

### 月历视图

按月展示订单的截稿日分布，手机上还支持左右滑动翻月。

### 时间条视图

以时间轴横条展示每个订单的开工日→截稿日区间，支持缩放（两周 / 一个月 / 三个月 / 半年），可以直接拖拽改日期：

- 拖 **右端** 改截稿日，拖 **左端** 改开工日，拖 **中间** 整条平移（开工日和截稿日一起移动）
- 自动吸附到天，保存后即时生效；开工日不能晚于截稿日，整条不能拖进过去
- 拖拽保存成功后会弹出带「撤销」按钮的提示，拖错了可一键恢复原日期

### 优先级说明

| 优先级 | 颜色 | 适用场景 |
|--------|------|----------|
| 🔴 高 | 红色 | 加急单、老客户优先 |
| 🟡 中 | 黄色 | 默认，正常排队 |
| 🟢 低 | 绿色 | 不急的单、练习 |

### 开稿管理（接稿状态与名额）

侧边栏「经营」分组的 **开稿管理** 页面集中管理：

- **接稿状态**：可约稿 / 已排满 / 休息中，客户打开主页第一眼看到的就是它
- **名额设置**：正式名额（同一时间最多接几单）+ 缓冲名额（满后允许多少单候补）
- **月度额度**：每月接单总量上限
- **队列行为**：满额后的排队/候补行为等开关

## 十、订单详情

点击任意订单进入 **订单详情** 页面：

### 状态流转

订单默认跟随你的 **自定义工作流**（在价格管理里配置的流程节点）：

- 详情页顶部显示 **流程进度条**（进度 当前/总数），点"推进到"按钮把订单推到下一节点
- 客户不满意可以 **↩ 打回上一节点**，订单标记为"修改中"
- 走完最后一个节点后交付订单（见第十一节）
- 不需要流程的订单可以 **关闭流程跟踪**，回到固定状态流转：待确认 → 已确认 → 制作中 → 已完成 → 已交付（任何状态可取消）

### 报价与最终价格

- **报价快照**：下单时系统自动生成的一段可读的报价描述（如"头像 ¥200 + 表情差分×2 ¥60，加急×1.5 → 总价 ¥390"）
- **最终价格**：这单实际成交的金额。自助下单时自动填入计算器总价，你可以随时改（改价需填写原因，系统自动记一条备注，方便回看）
- 报价快照和最终价格 **都可以编辑**——实际成交经常和计算器报价不同（面议、折扣、老客户优惠），改就完了

### 流程节点收款

- 开启收款的节点会显示 **已收 / 应收 / 差额**，可以一键快捷收款
- 改价、加钱后节点应收自动联动更新
- 所有收款记录在收款流水里，可以随时查看和撤销

### 订单级收款（记录收款）

- 订单详情的收款区显示 **已收 / 应收 / 待收**，点 **「+ 记录收款」** 录入客户实际打来的钱
- 正数收款 **不设上限**：客户多付时，超出应收的部分会以 **「多收 ¥X」** 醒目显示
- 负数用于录入 **退款/撤销**：必须填写原因，金额不能超过已收总额
- 金额不能为 0；金额在提交时校验，输入不合规会弹出提示（输入框本身不再限制范围）

> 💡 **完成 ≠ 结束**：订单到"已完成"（done）后仍可继续加附加项、记收款、退款；只有"已交付"（delivered）才是完全结束。改价在收款过后必须走"加/减一笔"条目，不能直接覆盖总价。

### 发布为作品

- 订单 **已交付（delivered）** 后，详情页出现 **「发布为作品」** 按钮
- 点击后弹窗里勾选要发布的完稿图（非图片文件置灰不可选）、填一个作品标题，确认后即发布到主页作品区
- 勾选几张图 = 发布几条独立作品（一行一图）
- 客户从作品大图点「立即约稿」会直接带出该作品对应的档位，无需重新选

### 订单图库

- 参考图区块已升级为 **订单图库**：支持拖拽 / 点击 / Ctrl+V 上传，客户图和画师图合计最多 20 张，图片带来源角标（客户/画师）
- 点击任意图片 **设为焦点图**——代表这个订单要画的角色，排期看板卡片上直接显示
- 焦点图支持三态显示：关（不显示）→ 小（缩略图）→ 大（预览图），在排期看板工具栏统一设置
- 已有焦点图时，拖入新图可直接替换

### 订单备注

- 记录客户的特殊要求、沟通要点，替代翻QQ聊天记录
- 备注支持 **附 1 张图**，可拖拽排序，可删除
- 状态变更、备注、带图备注统一混排在 **活动时间线** 里，一眼看清这单经历了什么

### 操作日志

订单详情里可以查看该订单的完整操作记录（谁在什么时候做了什么），支持筛选。

## 十一、交付作品

1. 订单走完最后一个流程节点（或固定状态改为"已完成"）后，出现 **上传交付** 入口——排期看板卡片上的「去交付」按钮、订单详情页都能打开交付窗口
2. 上传成品文件（支持 PNG/JPG/WebP/GIF/PSD/AI/PDF/ZIP/RAR/7z，最大 50MB）
3. 确认后订单状态变为"已交付"
4. 特殊情况（纯咨询、已线下交付等）可以选择 **无文件交付**，直接标记为已交付
5. 客户凭订单号在查询页或交付链接下载文件
6. 交付文件为**一次性下载**：客户完整下载一次后链接自动锁定，防转发盗用；如果客户确实没下完整，你可以在订单里「再许可」一次
7. 交付后想上主页展示？在订单详情点 **「发布为作品」**（见第十节），完稿图直接进作品区

## 十二、仪表盘

登录后进入 **仪表盘**（纸墨化布局）：

- **问候贴纸**：顶部问候区，每天首次进入有一次"逐字洇墨"的入场演绎，之后正常直出。点文字即可**换一句**；下方显示日期时段、今日新增订单金额 / 今日收入，还有一行**店公告**（点开看全文，看过即消）
- **统计卡片**：待处理新单 / 进行中订单 / 累计完成（点击可跳转到订单列表对应筛选）
- **挂牌**：可约稿 ⇄ 休息中的**真实切换**（翻牌动画，点牌即改接稿状态）；牌下是名额条（已用 / 总名额，满额时藤黄提醒），点击整块进入开稿管理
- **排期卷轴**：近 7 日排期的纸签长卷（花青=进行中、浅花青=未开工、朱砂=逾期、藤黄=待确认，带今日笔触线），点纸签进订单详情，头部可展开到排期看板；窄屏下隔日显示
- **账本待办**：待办清单一行一个动作（确认 / 开始制作 / 完成 / 交付等），点按钮原地推进（完成后 5 秒墨线冷却再操作下一项），完成的行沉到底部，可点「清账·撕页」收起；底部附**本月收入小结一行**
- **留言审核**：待审核的客户留言可以直接在这里通过 / 拒绝 / 回复（带待审数量角标）
- **订单动态**：最近操作的时间线
- **开张任务**：三步开张任务卡（传作品 / 设档位 / 分享主页），完成进度一目了然
- **快捷操作**：可自定义 3~9 个常用入口（在偏好设置里勾选）

> 💡 **看板模块开关**：侧边栏「门面」分组的**偏好设置**里，可以单独显示/隐藏「排期卷轴 / 留言审核 / 订单动态 / 开张任务」四块，不想要哪块就关掉哪个开关。
> 💡 收入走势已不在仪表盘展示（钱账信息在账本待办底部一行小结）；需要看历史收入走势时去**工具箱**的独立收入入口。

## 十五、主页模板切换

进入 **主页设置 → 模板与风格** 标签页，分两步定制你的主页：

### 第一步：选布局（页面怎么摆）

| 布局 | 风格 |
|------|------|
| 经典工作室 | 代表作横幅开场，桌面双栏，约稿按钮吸顶常驻 |
| 美术馆画廊 | 全屏画作开场，展签式名字，大小交错画廊 |
| 单页落地页 | 左文右图分屏开场，滚动侦测导航，适合品牌风格 |
| 画册工作室 | 暖米色纸感画册风，大图留白，作品像画集内页 |

### 第二步：选配色（页面什么气质）

| 配色 | 气质 |
|------|------|
| 纸 | 暖白宣纸，墨字，安静 |
| 墨 | 画廊深炭，层灰，克制 |
| 暮 | 蓝灰暮色，冷静 |
| 苔 | 深绿自然，温润 |

> 💡 配色只有"气质"之分，没有"亮暗"之分——喜欢亮色的客户看到浅色版，喜欢暗色的客户看到深色版，自动适配。主色（按钮/强调色）仍跟随访客的五色选择。

- 4 布局 × 4 配色 = **16 种主页风格**，随意组合
- 点选后点「保存设置」，客户刷新主页即可看到新样式
- 随时可切换，不影响画风、作品、须知等数据

## 十八、常见问题

**Q: 客户不愿意用网页怎么办？**
A: 完全没问题。让客户加你QQ聊，你自己在后台"手动录单"就行。网页只是展示和记录工具。

**Q: 我能关闭客户自助下单吗？**
A: 在开稿管理页把接稿状态改为"已排满"或"休息中"，客户就无法提交新订单了。

**Q: 参考图上传有什么限制？**
A: 下单时最多上传 5 张，每张最大 10MB，仅支持 JPG/PNG/WebP 格式。录单/下单后仍可以在订单图库里继续补充，客户图和画师图合计上限 20 张。

**Q: 动态口令（验证器 App）收不到/不会用怎么办？**
A: 动态口令不是短信，是手机验证器 App 生成的 6 位数字。首次使用先找管理员发二维码给你扫码绑定（见第二节）。换手机/手机丢了，找管理员"重新绑定"即可，旧手机上的绑定立即失效。

**Q: 手机上能用吗？**
A: 能。所有页面都做了移动端适配，手机、平板、电脑都可以用。

**Q: 报价和最终价格有什么区别？**
A: 报价是客户下单时计算器算出来的参考价，最终价格是你实际收的钱。可以改。比如客户聊完说"加个背景"，你直接改最终价格就行，报价快照也可以一起改。

**Q: 焦点图是干什么的？**
A: 焦点图代表这个订单要画的角色。设置了焦点图的订单，排期看板卡片上会直接显示角色缩略图，一眼看出这单画什么。

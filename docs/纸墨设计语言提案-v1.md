## 〇、缘起

用户对 v0.45 界面严重不满（"又方又圆 / 大片空间浪费 / 一条条像蛆"），项目归档暂停。2026-08-09 详谈确认：问题不在配色 token（纸墨盘地基是好的），而在**应用层没有戏、性格层没有魂**。本提案回答三个问题：后台是什么、看起来像什么、每个模块拿什么器物。

## 一、定位章：后台是什么

### 1.1 一句话定位

**画师后台 = 画师每天睁开眼就会看的"超级十字路口"，轻轻搂住画师。**

它不是：收银台（不经手钱）、客服台（不承载 QQ）、画板（不是画画的地方）。
它是：看今天画什么、最近有没有空、把别的平台的单子丢进来、甚至看看今天吃什么。

### 1.2 用户画像与安全原则

主要服务对象是男同福瑞画师群体——不被中文接稿环境包容，白天伪装、私下才能卸下伪装。因此：

> **身份表达 = 行为层的体贴，不是视觉层的标记。**
> 全站不出现任何圈层符号；不做"furry 平台"的明示。归属感来自"它连这个都记得"的体贴密度，来自普通、懂我、本能地喜欢。

### 1.3 反 AI 味（设计动机的另一半）

画师每天眼里只有屏幕：素材、自己的画、聊天软件，早就厌倦 AI 味（紫渐变、万物 Inter、卡片套卡片、图标方块堆叠）。纸与墨的意义 = **把"人的手作感"贴在画师身边**。

## 二、视觉章：看起来像什么

### 2.1 北极星

纸艺山水：米白手工纸折叠的立体山脉，水墨晕染，金线只勾山脊与亭台，深灰背景下的真实光影。
用户原话：**"自然、有美感、极为奢华但又很朴素"**——细节爆炸且不简单，却看起来很平凡。

### 2.2 核心公式（矛盾的解法）

> **色彩与造型克制，材质与细节爆炸。**

- 色彩预算锁死在颜料盘七色（花青/朱砂/石绿/藤黄/赭石 + 缓冲色 + 墨色四阶），**一枚新色都不许加**；
- 奢华预算全部花在"纸"上：纹理、厚度、光影、层次；
- AI 味的病根是反过来——颜色拼命喊、材质空空如也。

### 2.3 四条视觉规则

| 规则 | 内容 |
|------|------|
| 金只点睛 | 金（拟新增"泥金" token）只出现在三个时刻：完稿盖章、今日焦点、画师成就。平时全站无金；金出现 = 有喜事。使用规则比色值更重要 |
| 纸叠厚度 | 卡片是"一叠纸"不是"悬浮盒子"：可见纸边厚度 + 真实投影（升级 --sh-1/2/3 的用法），与 SaaS 浮卡划清界限 |
| 墨分五色做层次 | 分区优先用宣纸三阶（paper/paper2/card）与墨色四阶的浓淡，**边框降级为偶尔为之**，治"边框治国" |
| 微型亭台 | 空状态插画、日历小标记、加载小动作 = 山里的亭子：稀少、手工感、会心一笑。多了就成游乐园 |

## 三、问候章：后台唯一会说话的器官

### 3.1 人设（已拍板）

说话的人 = **创始人本人**。原型："每天早上第一班公车的司机——**安全开车是工作，贴心关照是人性**"。
嗓音：克制中带着友好，偶尔有点颠颠的，活人感。
画师每天第一次进来（无论 login 还是 cookies），要像"上了常坐的那班车，常见的那位司机微笑的迎面感"。

### 3.2 触发规则（用户设计，按人的节奏不按钟点）

```
触发条件：距上次登录 > 8 小时 且 距上次展示问候 > 20 小时
适用范围：login 会话与 cookies 会话均算
设计原因：中国也有只在晚上画画的画师——节奏跟着人走，不跟着地球走
```

- 问候文案池按节奏组织而非时段：主体池时间中性（「来了啊」「今天也辛苦了」）；深夜档偷看一眼时钟（零点后进来换深夜池）。
- 落地需求：画师表增加 last_login_at / last_greeting_shown_at 两个时间戳。

### 3.3 呈现规格

- **便签形态**：霞鹜文楷手写体，可微倾角，像贴在纸面上的留言条；
- **容器静、文字动**：便签渲染时已静默存在（不弹不跳）；问候文字 Ren'Py 式**逐句浮现**（按标点切分，句间小停顿），像司机开口说话；
- **只演一次**：浮现动画仅在触发那次播放；同日再进来就是安静贴着的字；
- **克制上限**：整段 1.5-2 秒内完成；prefers-reduced-motion 全文直出；
- **带画师本名**（{name} 替换，已实现）。

### 3.4 内容纪律

问候语是**手写资产**，不许 AI 批量生成（创始人的声音，生成的一眼假）。扩容方式 = 你写、系统管。

### 3.5 待排期（用户有意愿、此前碍于技术力）

1. 创始人落款（问候尾签名）——静态签名组件，小改；
2. 节日问候——问候池加"触发标签"字段（节日/时段/常规）；
3. 指定 QQ 画师的专属问候——问候加"画师覆盖"字段；
4. 倒时差画师的额外设置。

## 四、动效章

| 规则 | 内容 |
|------|------|
| 容器静、文字动 | 见 3.3；问候条永不"弹出来"，永远"等在那儿" |
| 墨色呼吸 | hover 不做位移，做墨色加深一档（ink3→ink2），像指尖按在宣纸上微洇 |
| 挂牌翻转 | 开关稿是全后台唯一允许有仪式感的动作（见五.3） |
| 既有纪律延续 | hover 不位移/不循环、后台导航稳定只动内容区、prefers-reduced-motion 兜底（均已拍板，不变） |

## 五、器物章：一模块一器物

> 总规则：
> ① 一件器物只许出现在一个模块；
> ② 每个模块的器物感只落在**一个结构 + 一个细节**上，其余全是纸；
> ③ 领不到器物的模块老老实实做纸面——宁可一半模块干净，不要满屋古董店。
> 检验标准：这个器物能不能帮画师一秒钟认出"我在哪个房间"？能就留，只是好玩就砍。

### 5.1 待办 = 账本（已拍板）

- 账本只有两类行：**要画的**（待推进，无金额）、**要收的**（带金额，右对齐淡墨）；
- 行间极淡的墨线（--line）分隔，只有横线不画竖线，列靠留白对齐；
- 状态不用 EP 标签，用**一枚笔点**：花青=进行中、朱砂=逾期（旁带一道极淡朱砂洇开）、石绿=已了；
- 完成行不划线，变淡并**沉到账本底部**（如结清旧页归档）。"不划线"先按此上线，**留待真实画师反馈**再定夺；
- 数字右对齐、等宽；
- 完成的动效与清账机制：见 5.7（讨论中）。

### 5.2 留言板 = 横置竹简（已拍板）

- 一条留言 = 一枚横简（窄长条、两端微圆、极淡纤维肌理）；**简与简之间留空隙不贴死**（物理治"蛆感"）；
- 左侧一条细装订绳贯穿所有简，兼作对齐线；
- 画师回复 = 小一号子简，挂原简下方偏右，像批注；
- 落位（**已拍板 2026-08-09**）：**客户端主页留言板用竹简**（待客以礼），**后台留言管理页用账本式列表**（做事以简）。

### 5.3 开关稿 = 挂牌（提案）

- 右侧安静位置的牌子翻转动作 = 店铺"营业中/今日闭店"挂牌；
- 全后台唯一仪式感动作；竖屏时落到"现在要干什么"下方。

### 5.4 快捷设置 = 百眼柜（已拍板）

- 右侧快捷设置区取百眼柜意象：一格一类、各归其位（现有 quick_actions 的结构化升级）。

### 5.5 工具箱 = 分类抽屉（已拍板方向，接 REQ-035）

- 导航栏只留**一个"工具箱"抽屉把手**，拉开是 **3-4 个分类格子**（水印/导出/菜单/收入等归类）；
- 治现状：工具项吃满导航栏、功能残缺；
- **收入走势从 Dashboard 移入工具箱**（见六.1）。

### 5.6 其余模块（候选，待逐个拍板）

| 模块 | 候选器物 | 状态 |
|------|---------|------|
| 排期看板 | 卷轴：横向时间线 = 展开的手卷；两端轴头为唯一结构件，看板底色为宣纸长卷，任务条沿用五色语义带；甘特/月历维持纸面，三视图性格由此分开 | **已拍板：收** |
| 素材/作品库 | 画筒 / 平放匣（收纳格 + 抽取感） | 待确认 |
| 设置 | 百眼柜已让给快捷设置；设置建议纸面 + 分节 | 待确认 |

### 5.7 待办完成的仪式（**已拍板**）

用户原有"撕纸"直觉；约束 = 最重要的都在顶上。四号提案 = **三档节奏**：

| 时机 | 动作 | 性格 |
|------|------|------|
| 单条完成（高频） | 石绿笔点"嗒"地盖上 → 墨色变淡 → 行沉底 | 安静的日常满足 |
| 沉底行积多（低频） | 画师主动点"清账"→ **撕页动效**整叠撕走沉底区 | 颠颠的仪式时刻 |
| 完稿交付（喜事） | 泥金盖章（2.3 金只点睛） | 唯一的金 |

理由：撕=删除语义，但完成的单子是画师的履历不是垃圾——账不自己撕，只在画师主动清账时撕；单条完成若每次都撕会高频吵闹，且误触即失。撕页只作用于已沉底的完成行，顶部在办行永远不动。

## 六、三条纪律（拍板级）

### 6.1 钱不进日报

Dashboard 是"今天"的房间，不是账房。大走势图令画师焦躁，**移入工具箱**。Dashboard 保留一行极安静的月度小结（"本月已收 ¥XXXX"，淡墨、无曲线、无涨跌箭头）——知道就好，不用心跳。（**已拍板：留**）

### 6.2 客户端跟宪法，不跟皮肤

| 层 | 归属 | 风格 |
|----|------|------|
| 平台公共件（下单流程/查单/交付/加载/空状态/按钮表单） | 平台的 | **纸墨** |
| 模板内容区（主页布局/作品陈列/模板配色） | 画师的 | 模板自身性格，纸墨不插手 |
| 质量宪法（留白/对齐/对比度/克制动效/反卡片堆叠） | 共同的 | 全平台同一部 |

比喻：拾绘是纸墨气质的老街，四个模板是街上的店——街有街的调性，店有店的招牌。
推论：公共件纸墨化是一次性批；四模板性格化逐个来（每模板一张风格卡：专属字体对 + 动效语言 + 密度档位 + 签名细节），互不阻塞。

### 6.3 命名说人话

器物进形态，不进名字。界面文案/导航名/功能名一律平实（画师年轻，古雅词制造距离）：
百眼柜→"设置"，账本→"待办"，竹简→"留言"，挂牌→开稿/关稿按钮本身。
**宪法里的比喻只允许影响布局、材质、动效。**

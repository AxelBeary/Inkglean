# 拾绘桌面版首页 · 视觉重做 r2 — 三方向原型

> 2026-08-25 · 依据《桌面首页视觉重做-设计需求书-20260825》执行
> 三个单文件 HTML 原型，浏览器直接打开即可拍板。交互：挂牌可翻、版面可显隐、行/卡 hover 墨色加深；均已声明 `color-scheme: light` 防深色滤镜；800×600 塌单列不破版。

## 方向 A「一轴 · 案头长卷」— proto-desktop-home-r2-A.html

**世界观：整个首页不是一堆卡片，而是一纸裱好的长卷——卷首题名，正文顺流而下，卷边题跋，卷尾拖尾。**

F 形视线落在卷首之后的第一行——逾期尾款（朱砂洇点置顶），随后钱与稿按缓急单列流下；收入、时间、留言全部退到右侧 296px 的"题跋"窄栏，分组只靠留白。全页无一格卡片，从根上消灭"长长短短"。核心意象就是"卷"本身：天地杆是唯一结构件，账本笔点落在行首，留言保留竹简形态但收敛为两枚横简，挂牌居卷首是全页唯一仪式动作。纸纹、裱边、纸叠厚度、卷尾淡墨山水全部落在"一张纸"上——材质爆炸而色彩克制。日常态无金。

## 方向 B「一席 · 俯案」— proto-desktop-home-r2-B.html

**世界观：画师低头看自己的书案——卷轴、账本、挂牌、竹简各居其位，光从左上来，影子落在案上。**

F 形左上是一轴横展的手卷（排期，三单一眼扫完），其下摊开线装账本（钱与待办，逾期置顶，完成行盖"讫"印沉底）；右列自上而下是挂牌与今日概览、经营纸卡、留言竹简；案沿压一张订单纸条。三行固定行高，物件各自撑满案位。全案四件器物，一件只留一个结构：卷轴留轴头、账本留装订线、挂牌留挂绳与翻牌、竹简留编绳；器物之外全是素纸——v3 的"戏多"被收进器物的边界里。日常态无金。

## 方向 C「一格 · 纸窗」— proto-desktop-home-r2-C.html

**世界观：一扇纸窗——现代严格网格做骨，宣纸与墨色做肉，窗格之间是"空"不是线。**

顶栏即今日焦点：全页唯一一点藤黄（"金只点睛"之今日焦点），三秒可读"明天截稿什么、谁欠多少钱"。主行三格严格等高，左格"今日要办"占半宽是主角；中格经营、右格留言安静候场；底行订单窄条压脚。全站只有挂牌一件器物，其余模块自觉做纸面：分区靠宣纸三阶底色与墨字浓淡，全页无边框、无浮卡投影，纸的厚度只留在窗格下沿的两层纸边。网格定死行高，内容只许截断不许撑高——效率优先到极致。

## 自检清单

- [x] 等高对齐：A 无卡片可参差；B 三行固定行高物件撑满；C grid 定死行高 + stretch
- [x] 三秒可读：逾期朱砂置顶 + 倒计时三色分级文字（剩 3 天/明天截稿/逾期 2 天）
- [x] 色彩预算：仅用宣纸三阶 + 墨色四阶 + 颜料盘七色，未加一枚新色（"金"以藤黄担当，且全站只在 C 的今日焦点出现一次）
- [x] 无抢戏元素：A 万物服从"卷"、B 戏收进四件器物、C 仅挂牌一件器物
- [x] 800×600：三向均塌单列不破版（已实测截图验证）
- [x] 深色滤镜：`<meta name="color-scheme" content="light">` + CSS `color-scheme: light`
- [x] 交互：挂牌翻转（含键盘 Enter/Space）、版面显隐开关、hover 只洇深不位移、`prefers-reduced-motion` 兜底
- [x] 收入纪律：仅一行"本月已收 ¥2,480"，无曲线无涨跌箭头
- [x] 时间统计诚实标注"数据只存本地，永不上传"
